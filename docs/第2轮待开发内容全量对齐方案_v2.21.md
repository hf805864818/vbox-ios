## 遗漏清单（123 → 130 项）

### 🔴 D-06 · 收藏按钮缺失 — P1

**问题**：iOS 详情页「剧情简介」标题右侧有 ❤️ 收藏按钮（[PlayerViews.swift:1328](file:///workspace/vbox/Views/PlayerViews.swift#L1328) `toggleFavorite`）；Flutter 详情页**无收藏按钮**。

**实锤**：`FavoriteUseCases` 已建（含 `isFavorite`/`toggleFavorite`/`removeFavorite` 全量方法，[favorite_usecases.dart](file:///workspace/lib/domain/usecases/favorite_usecases.dart)），但 [detail_page.dart](file:///workspace/lib/presentation/widgets/detail_page.dart) **全文件 0 引用** `FavoriteUseCases`/`isFavorite`/`收藏`。能力层与 UI 层断链（同 S-07 悬空组件模式）。

**开发步骤**：
1. `_DetailPageState` 注入 `FavoriteUseCases`（`context.read<FavoriteUseCases>()`）；
2. 新增 `bool _isFavorite = false` 状态；
3. `_load()` 完成后调用 `_checkFavorite()`（对齐 iOS `checkFavorite`）；
4. 在「剧情简介」标题行右侧新增 ❤️ 按钮（`Icons.favorite` / `Icons.favorite_border`，选中色 `VboxColors.selected`）；
5. 点击切换：`toggleFavorite` 后更新 `_isFavorite`；
6. 未收藏时新增记录（字段映射对齐 iOS `handleBatchDownload` 的 `FavoriteRecord`）。

**验收**：详情页有心形收藏按钮；点击切换收藏状态；收藏列表（`library_views.dart`）实时反映。

### 🔴 D-07 · 分享功能缺失 — P2

**问题**：iOS 详情页底部栏有「分享」按钮（[PlayerViews.swift:841](file:///workspace/vbox/Views/PlayerViews.swift#L841) `handleShare`，UIActivityViewController 分享「片名+简介」）；Flutter 详情页**无分享按钮**，全仓**无分享能力**（无 `share_plus` 依赖，无分享调用）。

**开发步骤**：
1. `pubspec.yaml` 新增 `share_plus` 依赖；
2. 新建 `ShareService`（封装 `Share.share` / `SharePlus.instance.share`）；
3. 详情页新增「分享」入口（底部胶囊栏 D-08 实现后接入，或按钮行加入）：
   - 分享文本 `"${vod.vodName}\n${vod.vodContent}"`（对齐 iOS `handleShare` 的 activityItems）；
4. 分享文案补 type 标签（对齐 iOS 可扩展 `ShareParams`）。

**验收**：详情页可触发系统分享；分享文本为「片名+简介」。

### 🔴 D-08 · 底部胶囊悬浮栏缺失 — P1

**问题**：iOS 详情页底部有**玻璃胶囊悬浮栏** `bottomBarLayer`（[PlayerViews.swift:1621](file:///workspace/vbox/Views/PlayerViews.swift#L1621)），含**播放/选集/下载/分享**四个按钮；Flutter 只有页面内嵌的「立即播放+下载」两个普通按钮，**无选集、无分享**。

**开发步骤**：
1. 新建 `DetailBottomBar` 组件（对齐 iOS `BottomBarButton`，capsule + ultraThinMaterial）；
2. 四项按钮：
   - 播放 → `_play()`
   - 选集 → 弹出半屏选集 sheet（D-09）
   - 下载 → `_showDownloadSheet()`（现有）
   - 分享 → `ShareService.share`（D-07）
3. `DetailPage` 用 `Stack` + `Positioned(bottom)` 挂载（替换 `_buildButtons` 内嵌按钮，或保留顶部「立即播放」按钮 + 新增底部栏，对齐 iOS 双入口）；
4. 底栏色值对齐 iOS `bottomBarActiveColor`（选中红 `E11D48`）/`bottomBarInactiveColor`。

**验收**：详情页底部有胶囊悬浮栏；四按钮功能齐全；选中态/图标对齐 iOS。

### 🔴 D-11 · 详情页视觉结构对齐 — P1

**问题**：iOS 详情页是**沉浸式**布局——「全屏背景图(封面) + 底部渐变遮罩 + 顶部透明区(30%) + Hero 标题(logo图+片名+类型标签+年份) + 蓝色胶囊播放按钮(黑字 93C5FD)」；Flutter 是**普通**布局——「AppBar + 左右并排小海报(120×168) + 普通 FilledButton」。

**开发步骤**：
1. 参照 iOS `backgroundLayer`/`contentLayer`（[PlayerViews.swift:1150-1242](file:///workspace/vbox/Views/PlayerViews.swift#L1150)）重构 `_buildBody`：
   - `Stack`：底层全屏 `PlatformAsyncImage`（TMDB backdrop/poster 优先，站点头图兜底）+ 黑色渐变遮罩（底部 55%）；
   - 顶部预留 30% 透明区；
2. 新建 `HeroTitleView` 等价组件：logo 图（TMDB logoURL）+ 片名 + 类型标签 + 年份；
3. 「立即播放」改为**蓝色胶囊按钮**（`93C5FD` 背景 + 黑字 + 圆角 28）；
4. 移除 AppBar（沉浸式 + 自定义返回按钮，重叠在图顶部）；
5. 元信息（备注/年份/地区/导演/主演）下沉到内容区，白字贴底。

**验收**：详情页呈沉浸式全屏封面布局；Hero 标题 + 蓝色胶囊按钮 + 底部胶囊栏（D-08）视觉对齐 iOS。

**开发步骤**：
1. `DetailPage` 引入 `download_overlay_widgets.dart`；

**验收**：详情页有悬浮下载按钮；点击弹下载管理弹窗；下载胶囊通知正确展示。
