## 1. 分析口径（四源 + 三条门槛）

1. **四源**：iOS 参照（`vbox/`）· Flutter 目标（`lib/` + `android/macos/windows`）· 契约层（`contract/`）· 方案文档（`docs/` 8 份）。
2. **「对齐」= 功能语义等价**，非文件 1:1（iOS Swift ↔ Flutter Dart 可多对一）。
3. **「缺」= 连语义等价物都没有**，需新开发。
4. **「部分」= 有底座/契约键但缺关键片段**。
5. **门槛①（v1.2）**：追加判「**是否可达**」——类/页面存在但**零引用**（如 MiniPlayer、`WelfareNativeRoute` 目标页）仍记"部分/缺"。
6. **门槛②（v1.3）**：追加判「**输出面是否可见**」——控制面/解码器存在不算对齐，**必须用户能感知（画面可显示）**方记"对齐"。
7. **门槛③（v1.4/本版）**：追加判「**是否有宿主/运行时**」——Dart 桥接类存在但**原生无宿主进程/运行时**（如 Node）仍记"部分"；以及「**封面是否真的显示出来**」（静默占位 = 未交付）。

## 4. 分域详述（含验收标准）

### 4.1 播放器核心（R）—— 本项目的命脉

**问题定性**（v1.3 已证，本版沿用）：四端播放器**控制面（open/play/pause/seek/volume/speed + state/progress 事件）已齐**，但**渲染输出面四端全空**。用户"能听声、看不见画面"。

| 端 | 控制面 | 渲染输出面 |
|---|---|---|
| Windows | ✅ libmpv | ❌ `vo=null`，`player_plugin.h:19-24` 载明纹理层未实现 |
| macOS | ✅ AVPlayer | ❌ 无；复杂封装直接 `E_BACKEND_UNAVAILABLE`，libmpv 依赖/二进制均未接线 |
| Android/TV | ✅ Media3 | ❌ 未绑定 Surface；libVLC 分支未实现 |

**MDK 决策落地要求（R-04）**：
- MDK 官方跨平台：Windows(x86/arm)·UWP·Linux·macOS·Android(API24+)·Android TV·iOS/tvOS·visionOS·OpenHarmony·树莓派/RockChip，**全平台硬解**。
- 弃用现三端异构（Media3/libmpv/AVPlayer），统一为 **MDK 渲染 + 控制**。
- 仍需保留 `PlaybackRoute` 路由 + `PlayerController` 抽象（它们与内核无关，直接复用）。
- 风险：MDK 为**闭源二进制**（免费）；须登记体积/合规，并保留降级预案（若 MDK 在 Windows 落地受阻 → 回退现 libmpv 方案）。

**验收标准**：四端（Android / Android TV / Windows / macOS）各播放 MKV/MP4/FLV/HLS + 一个复杂封装（RMVB/AVI/WMV）时**均能显示画面**，且失败可降级到下一后端，不白屏不卡死。

### 4.2 启动外壳（L）

- **闪屏**：iOS `VboxSplashView`（字母 V/b/o/x + swoosh 动画）+ `SplashGateMonitor`（最短 3.5s + 数据就绪淡出 + 10s 兜底）。Flutter 用 `CircularProgressIndicator` 顶替。
- **状态条**：iOS `ContentView:90` 全局 `RemoteSourceStatusBar`。
- **MiniPlayer**：`mini_player.dart` 已建但**零引用**，且启动未恢复 `music_queue_*`。
- **验收**：四端首屏见品牌闪屏动画，3.5s 后淡出；远程源加载期间顶部可见状态条；音乐播放中常驻 MiniPlayer 且重启可恢复队列。

### 4.3 Node 运行时（ND-01，本轮新增 · P0）

**现状拆解**（关键，别误判为"没做 Node"）：
- ✅ Dart 侧已做：`node_bridge_engine.dart`（HTTP ABI 客户端，实现 5 op：homeContent/searchContent/categoryContent/detailContent/playerContent）、`node_http_client.dart`（`127.0.0.1:58080/58083`）、`node_pan_client.dart`（网盘 Node 托管）、`node_credential_sync_service.dart`（12 网盘 provider 凭证同步）、`node_login_gateway.dart`、`node_bridge_engine`/`node_http_client` 复用标注。
- ❌ 三端原生缺：**Node.js 运行时宿主**——iOS 用 `NodeMobile/NodeRunner.mm` 常驻监听 58080；Flutter 三端 `android/macos/windows` **无任何 Node 内嵌/启动**，Dart 侧 `postJson('/spider/')` 会 `SocketException`（`node_bridge_engine.dart:162` 已写死该失败路径）。

**对齐方案**：三端分别内嵌 Node.js 运行时（`nodejs-mobile` / 预编译 Node 二进制随包分发），启动时拉起常驻进程监听 `58080/58083`，复用现有 Dart 侧 HTTP ABI 客户端。

**验收**：四端（含 Android TV）+ iOS 均能经 `127.0.0.1:58080/spider/` 执行 Node 站点脚本返回 `homeContent/searchContent`；网盘 Node 托管盘（光鸭/蜗牛）解析播放可用。

### 4.4 封面图（IMG-01，决策已定）

- iOS 是**统一代理入口**：`proxiedURL()` 重写为 `http://127.0.0.1:18080/...`，豆瓣/TMDB/福利**共用一个入口**；`allowedHosts` 13 主机。
- Flutter 现状是**分散 headers 注入**：`PlatformAsyncImage` 每处 `Image.network(headers:)`，**静默失败**（`errorBuilder`/`loadingBuilder` 直接返回占位盒，403 无任何上报）。
- **对齐 iOS 方案**：扩展 `go-proxy`（`package quarkproxy`，已有 `DiskCache` + 路由，加 `/image` 路由 + 白名单），封面 URL 统一重写进本地代理；`PlatformAsyncImage` 改为走代理 URL。
- **必须配套**：`errorBuilder` 上报状态码/主机/原因（替代静默占位）。
- **收益**：多封面对齐一处、连 Web 可显示、header/SSL/缓存集中、与网盘流代理（F-01）共用实例。

### 4.5 其余域（O/P/G/H/F/K/M/B/PF/A_RES）

上表 §3.3~§3.14 已列全。要点摘要：
- **O 源治理**：契约键 `fallback_enabled`/`custom_fallback_sites`/`user_parsers`/`bundle_sources_enabled`/`remote_default_manifest_url` **均已就绪，仅缺 UI + 引擎消费**——性价比最高。
- **P 日志**：P-01 分类是 P-03 筛选的前置，P-02 网络拦截为排查刚需。
- **G 音乐**：首段音频引擎 `UnavailableMusicAudioEngine` **不可发声**，须先补引擎再续段。
- **H 福利**：路由骨架已建（`WelfareNativeKind` + 5 类 serviceType），落地分支**仅 Toast**。
- **M**：登录注册已做，**缺推荐码/编辑昵称/分享**三小项。
- **PF 平台配置**：最易在真机失效（后台播放/备份导入导出/明文加载/自更新安装），随 K/L 批次逐项核销。
