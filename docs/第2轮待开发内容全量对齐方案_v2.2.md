## 4. 详细开发步骤方案

> 下述每个 P0/P1 项给完整步骤；P2/P3 项给要点步骤。**完整版见 v2.1 §3**（本版补 D-CAT，其余同）。

### 4.1 P0 核心（阻塞"能看到画面/封面/网盘"）

#### R-01 / R-04 渲染输出面 + MDK 内核（合并实施）
1. 引入 MDK SDK（Android `.aar`/`.so` + Windows `.dll` + macOS `.framework`），登记包体与闭源许可。
2. 各端原生新建 `MdkPlayerHost` 插件：init / setDataSource / setVideoSurface（Android）/ FlutterTexture（Windows·macOS）/ 事件回调。
3. Dart 侧 `MdkPlayerBackend` 实现 `PlayerBackend`，接入现有 `PlaybackRoute` + `PlayerController` 回退链。
4. Dart 新建 `VideoRenderView`（`PlatformViewLink`/`Texture` 多端分派）。
5. 保留降级：MDK 某端受阻 → 回退 Media3/libmpv/AVPlayer。
6. conformance 补 MDK 回归。
- **验收**：四端统一 MDK 显示画面，失败可回退。

#### R-02 播放器 UI 挂载
1. 新建 `PlayerPage`（横竖双态），挂 R-01 画面容器 + `PlayerControlsView`（已建零引用）。
2. `DetailPage` 点击"立即播放"从 Toast 改为 `Navigator.push(PlayerPage)`。
3. 接线控制条与 `PlayerController`（进度/播放暂停/倍速/选集/下一集）。
4. 挂弹幕 overlay + 字幕菜单。
- **验收**：点播放进播放页，画面+控制条+进度联动。

#### R-03 复杂封装回退
1. Android 引 libVLC `.aar` + `VlcPlayerHost`（`setDataSource`+`attachView`）。
2. macOS 接线 libmpv（依赖+二进制+`RenderContextPlayer`）。
3. 校验回退路由选择（复杂封装 → 回退后端；优先转封装 fMP4）。
- **验收**：四端各播 RMVB/AVI/WMV 成功或转封装成功。

#### ND-01 Node 运行时宿主
1. 选型 `nodejs-mobile`（移动）/ 预编译 Node（桌面）。
2. 三端 `NodeHostPlugin`（启动/停止/健康检查/重启），监听 58080；LX 58083。
3. 启动序列接入（L-05-3）。
4. `node_bridge_engine` 保持 HTTP ABI，加"进程不可达→自动拉起"。
5. 内置 `noderuntime/` 随包分发。
- **验收**：四端跑通 Node 站点 5 op；光鸭/蜗牛网盘解析可用。

#### IMG-01 封面统一代理
1. 扩展 `go-proxy` 增 `/image` 路由 + `allowedHosts` 白名单。
2. `PlatformAsyncImage` 统一 URL 重写进代理。
3. `errorBuilder` 上报主机/状态码/原因到 AppLog（替代静默）。
4. 与 F-01 共用 go-proxy 实例/缓存/端口。
- **验收**：封面前代理显示，403/超时有日志。

### 4.3 P2 功能补全

- **目标**：补 iOS `CategoryDetailView` 的类型/年代/排序筛选 + 订阅源标记。

  4. 变更筛选 → 重置分页重拉。
- **验收**：分类页可按类型/年代/排序筛选，订阅源有标记。
