**背景**：iOS 全仓 **20 个文件使用 WKWebView**（6 Views + 12 Services + 2 桥）；Flutter `pubspec.yaml` **无任何 webview 依赖**。各场景分别以「浏览器+粘贴/Worker 代理/放弃兜底」苟且替代。

**开发步骤**：

## 4. Bili-T · B 站域（2 项）

### 🔴 Bili-T1 · B 站直链解析 — P1

**问题**：iOS URL 含 `bilibili.com/b23.tv` 时走专用解析（SpiderManager.swift:4298-4312）：`api.bilibili.com/x/player/playurl?bvid=...&type=mp4&platform=html5` 取 `durl[0].url`；`extractBilibiliID`（:4371-4389）BV 号/av 号正则提取。Flutter 全仓 `b23.tv/bvid/api.bilibili.com` **零命中**。

**开发步骤**：
```dart
// 新建 lib/domain/services/bili_direct_resolver.dart
class BiliDirectResolver {
  static final _idRe = RegExp(r'(BV[0-9A-Za-z]{10}|av\d+)');
  Future<String?> resolve(String url) async {
    final id = _idRe.firstMatch(url)?.group(1);
    if (id == null) return null;
    final r = await _http.get('https://api.bilibili.com/x/player/playurl'
        '?bvid=$id&type=mp4&platform=html5');
    return r.json['data']['durl'][0]['url']; // 带 Referer 播放
  }
}
```
接入 `PlaybackRouteResolver`（bilibili.com/b23.tv 前缀分流）。**验收**：B 站/BV 链接直接可播。

### 🔴 Bili-T2 · DASH 流检测 + 兼容内核降级 — P1

## 8. Img-X · 图片体系（4 项）

### 🔴 Img-X1 · AES 加密图片解密 — P1

**问题**：iOS `AESImageDecryptor` 支持 **CBC/ECB 双密钥对**解密每日大乱斗封面（PlatformImageLoader.swift:51-144），`dailyBattle` 模式贯穿加载与 data: 分支（:303-309、374-381）；Flutter `PlatformAsyncImage` **无 AES 分支——大乱斗封面直接不可显示**（UI-C1-c 交付后的显性 bug）。

**开发步骤**：
```dart
// platform_async_image.dart 或独立 decryptor
class AesImageDecryptor {
  static Uint8List? decrypt(Uint8List data, AesImageKeyPair k) {
    if (k.mode == 'cbc') return _cbc(data, k.key, k.iv);   // pointycastle
    return _ecb(data, k.key);
  }
}
// coverFor() 加 mode 参数：dailyBattle → 先解密再 decode
```
**验收**：大乱斗列表封面正常显示。

### Img-X2 · 缓存上限管控 — P2

**步骤**：main.dart `PaintingBinding.instance.imageCache.maximumSize = 300; maximumSizeBytes = 80 << 20;`。**验收**：内存 profiling 达标。

### Img-X3 · 轮播预加载器 — P3

**问题**：iOS `ImagePreloader.preloadBatch` 后台预取当前+后续 2 项（DoubanService.swift:122-166）；Flutter 无。

**步骤**：Banner/横滚区 `precacheImage` lookahead 2 项。**验收**：轮播翻页无闪白。

### Img-X4 · 并发去重 + 缓存键含 headers — P3

**问题**：iOS loadingTasks+NSLock 防同图并发重复下载（PlatformImageLoader.swift:151、167-183）；缓存键 = `cleanURL#mode#sortedHeaders`（同 URL 不同 UA/Referer 不串缓存，PlatformAsyncImage.swift:118-126）；Flutter 依赖框架隐式行为。

**步骤**：自定义 `ImageProvider`（键含 headers hash）+ in-flight Map 去重。**验收**：同图不同源不串缓存。

## 9. Err-Y + Cat-Z（3 项）

### Err-Y1 · 垂直域错误细分 — P3

**问题**：iOS 有 20 个服务级 LocalizedError 枚举（DriveError/M115Error/AuthError/BiliAuthError/NodeRuntimeError 等），可区分「token 过期需重新授权」vs「网络不通」；Flutter 这些域一律折叠为通用 NetworkFailure/SpiderFailure/UnknownFailure（failures.dart:80-216）——**无法引导用户做不同动作**。

**步骤**：Failure 扩展子类（`AuthExpiredFailure`/`DriveQuotaFailure`/`NodeRuntimeFailure`，附 ErrorCode 稳定码）；授权中心/网盘播放按类型分流提示（重新授权/清理缓存/重启 Node）。**验收**：token 过期提示「重新授权」而非「网络错误」。

### Err-Y2 · 播放器错误日志联动 — P2

**问题**：iOS `ErrorViewWithLogs` 错误同时携带日志数组供绿色浮层排查（PlayerViewsV2.swift:7614-7661）；Flutter `_ErrorRetry` 仅文案+重试（12 处）。

**步骤**：UI-F10 错误视图加「查看日志」入口（读 AppLog 环形缓冲过滤播放会话）+ 调试浮层展示。**验收**：播放失败可查上下文日志。

### Cat-Z1 · 豆瓣分类页订阅源联动 — P2

**问题**：iOS `CategoryDetailView` 有**订阅源模式**（`hasSubscription` + `SubscriptionSiteGrid` :286——豆瓣分类页内直接浏览订阅站点内容，豆瓣筛选器复用于站点筛选）；Flutter douban_category_page.dart 无订阅联动（订阅独立在另一页）。

**步骤**：分类页加「订阅源」视图切换 + SubscriptionSiteGrid（站点卡片网格，点击进站点分类列表，筛选器参数透传）。**验收**：豆瓣分类筛选可驱动订阅站点浏览。
