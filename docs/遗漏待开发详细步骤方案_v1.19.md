# vbox 遗漏待开发详细步骤方案 v1.19

> **版本**：v1.19 —— 在 [v1.18](computer:///workspace/docs/遗漏待开发详细步骤方案_v1.18.md)（23 项未开发 + 验收 3）基础上，记录 **Wave F 首批（账号 + 诊断域收尾）**：M-账1 · 推荐码字段 → M-账2 · 分享 vbox → M-账3 · 头像更换 → M-账4 · 下载管理入口 → S-设4 · 网络日志分类/全局拦截 → E-12 · 分享解析入口收敛。
> **核对日期**：2026-10-06
> **数据源**：仓库代码（HEAD `644bcc6` + 本批工作区改动）+ iOS 源码（`vbox/Views/ProfileView.swift` · `vbox/Views/SettingsViews.swift` · `vbox/Views/PlayerViewsV2.swift` · `vbox/Services/UpdateManager.swift`）+ v1.18
> **核心原则（强制）**：UI 层一律以 iOS 端为准（35 张真机截图 + 54 个 Swift 源码）。

> **本轮要点**：
> 1. **账号域收尾**：个人中心登录弹窗补齐 **上级推荐码**（M-账1，随登录落 `referrer`）；**分享 vbox** 由占位改为系统分享面板（M-账2，`share_plus` + `UpdateManager.shareURL` 对齐）；**头像更换**落地（M-账3，`image_picker` 相册选图 → 压缩最长边 200px → Base64 落 `avatar_image`，未登录默认头像改用软件图标）；**下载管理入口**接线到既有管理弹窗（M-账4）。
> 2. **诊断域收尾**：日志新增 **模块分类** `LogCategory`（对齐 iOS `LogViewer`），HTTP 统一网关落 **网络分类日志**（方法/地址/耗时/字节），日志查看页新增 **模块筛选栏**（S-设4）。
> 3. **入口差异收敛**：网盘分享解析入口从「授权中心」迁移至「推送播放详情页」——识别为网盘链接时按钮由「立即播放」改为「展开选集」，点击进入网盘选集（E-12，对齐 iOS 播放器 `handleDriveUrl`）。
> 4. **多端应用图标统一**：Android / Android TV（同 APK 双形态，共用 `ic_launcher`）/ Windows / macOS 的 Launcher 图标全部以 **iOS `AppIcon`（1024²）为唯一源**重生成，像素级一致（RMS = 0.00）；同时导出 `assets/brand/app_icon.png` 供默认头像复用。
> 5. **未开发项 23 → 17**（P0 **0** · P1 **2** · P2 **9** · P3 **6**）；验收项仍 3。
> 6. **附带修复**：补齐 M-账1 登录主机的半接线缺口（推荐码字段此前仅在 `VboxLoginSheet` 可选渲染、真实登录流未注入）；修复 E-12 遗留的编译期错误（`_playSingle` 被 `await` 但返回 `void`）；清零 `flutter analyze` 2 处 info（`prefer_const_declarations` / `unnecessary_import`）。
