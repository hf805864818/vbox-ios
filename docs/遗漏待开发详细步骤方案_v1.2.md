## 3. Down-M · 下载管理域（4 项）

### 🔴 Down-M1 · 下载地址解析器 delegate 注入（生产 bug）— P0

**问题**：`DefaultDownloadUrlResolver.resolve` 只有「直链判定 + delegate」两分支（download_manager.dart:94-117），**delegate 已设计但 app.dart:182 生产装配 `DownloadManager()` 从未注入** → 需要蜘蛛 playerContent 解析的站点资源下载一律落 `unsupported` 失败。iOS 对应链路：非直链依次走 `SpiderManager.getPlayerContent` → `parsePlayUrl` 兜底（DownloadManager.swift:211-233）。

**开发步骤**：
```dart
// app.dart 生产装配修复
_downloadManager = DownloadManager(
  urlResolver: DefaultDownloadUrlResolver(
    delegate: SpiderPlayerContentResolver(spiderUseCases), // 新建：包装 playerContent + parsePlayUrl
  ),
);
```
**验收**：JS/CMS 蜘蛛站点的剧集可解析直链入队下载。

### 🔴 Down-M2 · 网盘资源下载链路 — P1

**问题**：iOS `resolveCloudDriveURL` 统一走 `CloudDriveManager.resolvePlayURL`（DownloadManager.swift:243-257），`sourceType == "cloud"` 分发（:183-187）支持夸克/阿里/UC/115/123/天翼/移动/迅雷网盘分享下载；Flutter 下载器**无任何 cloud 分支**。

**开发步骤**：
1. `DefaultDownloadUrlResolver` 加 cloud 分支（`sourceType == 'cloud'` → F-P 族 PanPlayer.resolvePlayUrl 复用）；
2. 依赖 Wave 2 的 F-P17 凭据中心；
3. 详情页 D-12 批量下载 sheet 对网盘资源标记 cloud。

**验收**：网盘资源可下载（含需要解析的分享链接）。

### Down-M3 · TS→MP4 转封装 — P2

**问题**：iOS 三级兜底产出 MP4（AVMutableComposition 合并 → AVAssetExportSession Passthrough → 最终保留 .ts，DownloadManager.swift:774-960）；Flutter M3U8 仅拼接输出 `.ts`（download_manager.dart:561-564，注释自认无 AVFoundation）——**用户拿到 TS 而非 MP4**。

**开发步骤**：
1. Android：MediaExtractor/MediaMuxer MethodChannel（或 ffmpeg_kit_flutter 转封装）；
2. 桌面：media_kit 自带 muxer 或 ffmpeg；
3. 失败兜底保留 .ts（对齐 iOS 最终兜底）。

**验收**：M3U8 下载完成产出 .mp4 可直接播放；直链 .ts 也转 MP4。

### Down-M4 · 完成行操作（播放/保存到文件）— P2

**问题**：iOS 完成行支持播放本地文件（ProfileView.swift:1605）、保存到文件（:1722）、保存到相册（:1740-1806）；Flutter 完成行仅删除（download_overlay_widgets.dart:801-804 差异登记自述）。

**开发步骤**：完成行加「播放」（PlayerController.open(File)）+「保存到文件」（file_picker/file_saver）；「保存到相册」为 iOS 平台能力豁免（登记不移植，NS）。

## 7. Mag-Q · 磁力链域（1 项）

### Mag-Q1 · 磁力链线路能力 — P2

**问题**：iOS **随包内置** kstore bundle（`vbox/Resources/noderuntime/bundles/kstore_index.js`），其中 qwmkv（七味|4K）站点适配器有完整磁力链路：`magnet:` 独立 providerId + 磁力链直接透传播放 + 详情页 `a[href^="magnet:"]` 抽取生成「磁力链接」线路 + 40 位 hash 规范化；Flutter 工程**无内置 bundle**（pubspec assets 仅启动图），只能依赖远程下发（remote_node_bundle_url）——远程仓库未覆盖时无磁力链线路。

**开发步骤**：
1. 并入 ND-02（bundle 按需下载）：确保远程 bundle 含 kstore；
2. 播放器侧支持 `magnet:` 直透（内核需支持或走代理转流）；
3. 详情页线路识别 magnet 前缀。

**验收**：七味 4K 站磁力线路可选可播。
