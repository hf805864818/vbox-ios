## 第二梯队 · P1（核心功能，本周内）

### UI-F1 · 播放器视频区手势（亮度/音量/快进快退/单击显隐）

**问题**：iOS `PlayerViewsV2` 有完整视频区手势系统（UIPanGestureRecognizer + UIPanGestureRecognizer），Flutter 播放器视频区 **零手势处理**。

**iOS 参考**：`PlayerViewsV2.swift:384-415`（UIPanGestureRecognizer + UITapGestureRecognizer 手势注册）+ iOS 参考图横屏效果 IMG_5220-5228（左右滑动快进快退、上下滑动亮度/音量）。

**Flutter 现状**：`player_controls_view.dart` 只有顶栏/底栏的 `onTap`，视频区无任何手势监听。

**开发步骤**：
1. 新建 `PlayerGestureLayer`（`GestureDetector` 包装层，覆盖整个视频区）；
2. 上下滑动分区域：左半屏 → 亮度调节，右半屏 → 音量调节；
3. 左右滑动 → 快进快退（滑距映射时间偏移）；
4. 单击 → 显隐控制栏（与双击互斥）；
5. 双击 → 暂停/播放（接 UI-E1）；
6. 手势进行时显示对应 HUD（亮度/音量/快进秒数）；
7. 对齐 iOS 手势灵敏度与响应延迟。

**验收**：上下滑动可调亮度/音量；左右滑动可快进快退；单击显隐控制栏；双击暂停；HUD 提示与 iOS 一致；手势不冲突。

### UI-F2 · 跳过片头片尾设置面板

**问题**：iOS `PlayerViewsV2.swift:10842` 有 `SkipSettingsPanelV2`（片头片尾开关 + 秒数设置），Flutter 完全缺失。

**iOS 参考**：`SkipSettingsPanelV2`（片头开关 + 片头秒数 + 片尾开关 + 片尾秒数，深色面板 + 白色文字）。

**Flutter 现状**：`skip`/`intro`/`outro` 全仓 0 引用。

**开发步骤**：
1. 新建 `SkipSettingsPanel`（半屏浮层，对齐 iOS 深色面板形态）；
2. 片头开关 + 秒数输入（0-300 秒）；
3. 片尾开关 + 秒数输入；
4. 播放时自动跳过（时间到达片头结束点/片尾开始点时 seek）；
5. 状态持久化到 prefs（`skip_intro_enabled`/`skip_intro_seconds`/`skip_outro_enabled`/`skip_outro_seconds`）。

**验收**：面板形态与 iOS 一致；自动跳过生效；状态持久化；片头/片尾可分别开关。

### UI-F3 · 弹幕搜索面板

**问题**：iOS `PlayerViewsV2.swift:10272` 有 `DanmakuSearchPanel`（按番剧名搜索弹幕源 + 选集匹配），Flutter 完全缺失。

**iOS 参考**：`DanmakuSearchPanel`（搜索框 + 番剧结果列表 + 选集列表 + 加载指定集弹幕）。

**Flutter 现状**：`DanmakuSearch` 全仓 0 引用。

**开发步骤**：
1. 新建 `DanmakuSearchPanel`（半屏浮层）；
2. 搜索框（自动带入当前视频标题）；
3. 番剧结果列表（标题 + 封面 + 匹配度）；
4. 选集列表（当前视频对应集数）；
5. 选中后加载对应弹幕；
6. 对齐 iOS 面板形态（深色背景 + 白色文字 + 磨砂皮肤适配）。

**验收**：可按番剧名搜索；选集匹配正确；加载后弹幕正常显示；面板形态与 iOS 一致。

### UI-F4 · 播放器设置面板

**问题**：iOS `PlayerViewsV2.swift:9464/9633` 有 `PlayerSettingsViewV2`/`PlayerSettingsPanelV2`（播放速度 + 其他播放器偏好），Flutter 缺失独立设置入口。

**iOS 参考**：`PlayerSettingsViewV2`（NavigationView + List + Section「播放速度」+ 0.5x/1.0x/1.5x/2.0x 选项）。

**Flutter 现状**：倍速选择已有 `speed_picker_panel.dart`，但**缺少独立的播放器设置面板**（整合倍速 + 其他偏好）。

**开发步骤**：
1. 新建 `PlayerSettingsPanel`（半屏浮层/全屏页，对齐 iOS 设置面板形态）；
2. 播放速度选择（0.5x/1.0x/1.5x/2.0x/2.5x/3.0x）；
3. 自动连播开关（接 UI-F5）；
4. 后台播放开关（接 UI-D3）；
5. 跳过片头片尾入口（接 UI-F2）；
6. 长按倍速设置入口（接 S-04）；
7. 对齐 iOS 面板深色主题 + 分组列表形态。

**验收**：面板形态与 iOS 一致；各项设置可读写；状态持久化。

### UI-F5 · 字幕系统完整实现（SRT/VTT/ASS 解析 + 加载 + 显示 + 颜色/字号）

**问题**：iOS `PlayerViewsV2.swift:1752-1830` 有完整字幕系统（SRT/VTT/ASS 解析 + 二分查找 + 颜色切换 + 字号设置），Flutter 只有 `String? subtitle` 字段（字幕文案）。

**iOS 参考**：`loadSubtitle(url:)` / `updateSubtitle(currentTime:)` / `subtitleColor` / `subtitleFontSize` / `subtitleColorIndex`。

**Flutter 现状**：`player_controls_controller.dart:47` 只有 `String? subtitle`（静态文案），无解析/无动态更新/无样式控制。

**开发步骤**：
1. 新建 `SubtitleParser`（SRT/VTT/ASS 三格式解析 → `List<SubtitleCue>`）；
2. 播放器加字幕加载入口（文件选择器/URL 输入）；
3. 播放器定时器按当前时间二分查找对应字幕；
4. 字幕显示层（叠加于视频上方，底部居中）；
5. 字幕设置面板（字号 12-24 / 颜色 白/黄/青 / 位置 下/中/上）；
6. 对齐 iOS `SubtitleSettingsPanelV2` 形态。

**验收**：SRT/VTT/ASS 均可解析；字幕与时间同步；字号/颜色/位置可调；面板形态与 iOS 一致。
