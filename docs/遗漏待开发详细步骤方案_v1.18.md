# vbox 遗漏待开发详细步骤方案 v1.18

> **版本**：v1.18 —— 在 [v1.17](computer:///workspace/docs/遗漏待开发详细步骤方案_v1.17.md)（26 项未开发 + 验收 3）基础上，记录 **Wave D（源治理）全批交付**：O-源3 · 站源管理/切片源 → O-源1 · 兜底源开关 → O-源2 · 自定义解析器。
> **核对日期**：2026-10-06
> **数据源**：仓库代码（HEAD `644bcc6` + Wave D 工作区改动）+ iOS 源码（`vbox/Services/SpiderManager.swift` · `vbox/Views/SettingsViews.swift` · `vbox/Views/PlayerViewsV2.swift`）+ v1.17
> **核心原则（强制）**：UI 层一律以 iOS 端为准（35 张真机截图 + 54 个 Swift 源码）。

> **本轮要点**：
> 1. **源治理贯通**：设置页新增「切片资源」「站源管理」两分区，落地 **兜底切片源开关**（`fallback_enabled`）、**自定义切片源管理**（`custom_fallback_sites`）、**自定义解析器管理**（`user_parsers`）、**站源启停**（SQLite `zhanyuan.isActive`，含「全选」批量）。
> 2. **三页对齐 iOS**：新增 [切片资源管理页](file:///workspace/lib/presentation/pages/settings/fallback_slice_source_page.dart)（对齐 `FallbackConfigView`）、[解析器管理页](file:///workspace/lib/presentation/pages/settings/parser_manage_page.dart)（对齐 `ParserConfigView`）、[站源管理页](file:///workspace/lib/presentation/pages/settings/zhanyuan_site_manage_page.dart)（对齐 `ZhanyuanSiteManageView`）；复用 `VboxSettingsSection/Row`、间距/字重/角标令牌，原「更多设置（待实现）」占位分区移除。
> 3. **链路接线**：搜索页在开关开启时**并入兜底切片源搜索**（受 `fallback_enabled` 约束）；播放入口接入**解析器兜底**（远程默认 + 自定义，非直链时尝试）与**兜底切片源站点回退**（合成 key `fallback_<host>` → 详情路由）。
> 4. **未开发项 26 → 23**（P0 **0** · P1 **2** · P2 **13** · P3 **8**）；验收项仍 3。
> 5. **附带修复**：设置页新增分区导致 Golden `settings_portrait` 像素基线失效（diff 23.43% / 219277px），已重生成基线；并将播放解析器链路由「仅用户解析器」修正为「远程默认 + 自定义」合并（对齐 iOS `subManager.parses + customParsers`）；补测 `app.dart` / `main.dart` 冷启动链路，覆盖率门禁 **69.8% → 71.1%** 达标；修复三张源治理管理页经设置页路由跳转时未注入用例（改由 Provider 兜底读取，保证「远程默认源」/ 站源清单可见）。
