### 🔴 F-P06 · `PlaybackEpisode` 网盘字段扩展 — P0

**问题**：见发现 A。Flutter 剧集模型缺网盘字段，无法识别/携带网盘参数。

**开发步骤**：

   - `pan123FileId` / `pan123ETag` / `pan139ContentId` / `pan139CatalogId`
   - `pan189FileId` / `nodePlayID` / `nodeDriveType`
   - `headers` / `useCompatibility`
2. `PlaybackUrlParser` 扩展：解析网盘专属字段（如 `quarkFileIndex` 从 URL/分享链接提取）；
3. 详情页 `_episodesForLine` 按 `sourceType` 分组展示；
4. 播放页按 `sourceType` 分发到对应播放函数。

**验收**：详情页能识别网盘类型；播放页能携带网盘参数；切集时字段不丢。

### 🔴 F-P08 · 夸克原生播放链路完整实现 — P1

4. 线路偏好 `quarkRoutePreference`（原画/普画/自动）；
5. 切集时保持进度（`currentEpisodeIndex` 更新 + `restorePlaybackProgress`）。

**验收**：夸克原生盘可播放；原画失败自动兜底；线路偏好生效；切集进度保留。

### 🔴 F-P12 · 网盘 headers/cookie 处理统一层 — P2

**问题**：iOS 各网盘有专属 headers/cookie 处理；Flutter 无统一层。

**开发步骤**：
1. 新建 `PanHeadersBuilder`（对齐 iOS `mergedBaiduStreamHeaders` + `normalizeBaiduCookie`）；
2. 各网盘专属 headers 规则：
   - 百度：BDUSS/STOKEN 合并 + `User-Agent` 伪装 + `Referer`；
   - 夸克：Cookie + `User-Agent`；
   - UC：Cookie + Token；
   - 迅雷：Cookie；
   - 115：Cookie/CID；
   - 123：Cookie/Token；
   - 139：Cookie/Session；
   - 189：Cookie/账号密码；
3. headers 持久化（`CloudDriveCredential`）；
4. headers 注入播放器（`PlayerSource.headers`）。

**验收**：各网盘 headers 正确；Cookie 合并无误；持久化生效。
