## 1. iOS 播放内核矩阵全貌（7 后端，★本版修正认知）

| # | 后端 | 类型 | iOS 证据 | Flutter 现状 | 处置 |
|---|---|---|---|---|---|
| 1 | **AVPlayer（system）** | 枚举 | `PlayerEngineType.swift:5` + `AVPlayerEngine.swift` | macOS 有 AVPlayer（无渲染扩展） | R-01/R-03 |
| 2 | **VLC** | 枚举 | `PlayerEngineType.swift:6` + `pod 'MobileVLCKit'`（MKV/HEVC/10bit/HDR/多音轨） | Android 有 libVLC 依赖但未实现；Win/macOS 无 | **R-03** |
| 3 | **MPVKit** | 枚举 | `PlayerEngineType.swift:7` + `Libraries/MPV/MPVKit.xcframework` | 无（Apple Metal 专有） | NS-02 |
| 4 | **libmpv** | 枚举 | `PlayerEngineType.swift:8` + `LibMPVBackend.swift` | Windows libmpv 依赖已声明（`vo=null`） | R-01/R-03 |
| 5 | **MDK** | 枚举 | `PlayerEngineType.swift:9` + `pod 'swift-mdk'`（★已在生产，复杂封装首选 + 帧回退 PiP） | 无（R-04 要落地） | **R-04** |
| 6 | **IJKPlayer（B站）** | 专用桥接 | `IJKPlayerRepresentable.swift`（`#if canImport(IJKMediaFrameworkWithSSL)` + tag 9527） | 无 | **NS-15** |
| 7 | **AliPlayer（阿里云）** | 专用桥接 | `AliPlayerRepresentable.swift` + `AliyunPlayer.framework` | 无（仅 extscreen 授权） | NS-01 |

> **结论**：iOS 用「7 后端」覆盖不同资源；Flutter 用 **MDK 一统四端**后，MDK 覆盖复杂封装/特殊格式（等价 VLC+MDK 的职责），B站 IJK / 阿里 AliPlayer 两个专用内核**不移植**（NS-01/NS-15）。**MDK 已在 iOS 验证，四端复用是低风险路径。**

## 5. 详细开发步骤方案（关键路径更新版）

> 完整步骤见 [v2.2 §4](computer:///workspace/docs/第2轮待开发内容全量对齐方案_v2.2.md)。本版对 R-03/R-04 步骤做细化（依据内核矩阵 + MDK 已生产）依旧：

### R-04 MDK 内核一统（★步骤强化：有 iOS 生产先例）
1. 复用 iOS 已验证的 `swift-mdk` 选型，确定四端 MDK 版本一致性（iOS 用 swift-mdk，其余端用官方 MDK SDK 对应平台产物）。
2. Android：MDK `.aar`（含硬解 aMediaCodec/FFmpeg）。
3. Windows：MDK `.dll`（D3D11 渲染）。
4. macOS：MDK `.framework`（Metal）。
5. Dart `MdkPlayerBackend` 实现 `PlayerBackend`，接入 `PlaybackRoute` 回退链（**替代复杂封装场景**，对应 iOS 用 MDK 作复杂封装首选）。
6. 降级：MDK 失败 → 回退 VLC（R-03）→ 回退系统后端。
- **验收**：四端复杂封装（MKV/HEVC/10bit）走 MDK 稳定播放；失败回退 VLC。

### R-03 复杂封装回退（★步骤明确 VLC）
1. Android 引 `libVLC`（org.videolan.android:libvlc-all）→ `VlcPlayerHost`（`setMedia`+`attachViews`）。
2. Windows：libVLC `.dll` + `VlcPlayerHost`。
3. macOS：MobileVLCKit 等价（或直接由 MDK 覆盖，则 macOS 免 VLC）。
4. 校验路由：复杂封装 → MDK 优先 → VLC 回退 → 系统后端。
- **验收**：四端各播 MKV/HEVC/10bit/HDR/多音轨成功（MDK 或 VLC）。**

## 6. 最终关键路径（含内核矩阵）

```
R-04(MDK 一统，iOS 已有先例) ──→ R-01(渲染面) ──→ R-02(播放页)
                                   └─→ R-03(VLC 复杂封装回退，MDK 失败时)
ND-01 + IMG-01 + F-01   并行 P0
L-05(启动编排) ← K-01 + ND-01 + IMG-01 + 转封装端口
D-CAT(分类筛选) 独立
其余 P2/P3 按 v2.2 §4 顺序
```

**建议顺序（不变）**：① R 族（MDK→渲染→播放页→VLC 回退）→ ② IMG-01+F-01+ND-01 → ③ L-01~L-03+L-05 → ④ D-CAT → ⑤ K 族 → ⑥ O 族 → ⑦ P 族 → ⑧ G 族+C-DM → ⑨ M+F-02/F-03+B-WV → ⑩ H 族 → ⑪ A-RES+PF-01。
