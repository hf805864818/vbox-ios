## 0. 本轮深扫 · 最核心发现

### 🔴 发现 A：**`PanPlayer` 全仓零消费**——网盘播放链路从未被详情页调用

[detail_page.dart](file:///workspace/lib/presentation/widgets/detail_page.dart) 全文件 grep 实测：**无 `PanPlayer` / `pan_player` / `网盘` / `CloudDrive` 引用**。详情页「立即播放」只走 `PlayerController.play()`，**没有任何网盘分支**。

iOS 详情页/播放页有完整网盘分支：
- `handleCloudVideo`（`:2916`）→ 云盘视频统一入口
- `handleDriveUrl`（`:3012`）→ 按盘类型分发
- `handleNodeManagedDrive`（`:3696`）→ Node 托管盘统一入口

### 🔴 发现 B：**原生网盘（夸克/百度/UC）直接报错**——`PanPlayer._guardChannel` 显式抛出

[pan_player.dart:177-191](file:///workspace/lib/platform/player/pan_player.dart#L177) 对原生盘：
```dart
case PanPlayChannel.native:
  throw PanPlayException('${type.displayName} 原生路链尚未接入（待后续批次）');
```

iOS 端原生盘有完整实现：
- `playQuarkEpisode`（`:6035`）——夸克原生
- `startBaiduPlayback`（`:2259`）——百度原生
- `playUCEpisode`——UC 原生

### 🔴 发现 C：**百度网盘 Cookie 合并 + 本地代理流缺失**

iOS 有完整百度链路：`mergedBaiduStreamHeaders`（`:2611`）+ `normalizeBaiduCookie`（`:2638`）+ 本地代理 `baidu-stream`（`:1128`）+ 缓存进度监听（`:2440-2495`）。Flutter `BaiduProxyTransport` 有签名传输但**未接入播放器链路**。

### 🔴 发现 D：**夸克线路偏好（原画/普画）缺失**

iOS `quarkRoutePreference`（`:1008`）+ `vbox_route=original/transcode`。Flutter 无此字段。

### 🔴 发现 E：**百度网盘多文件选集 + 预加载缺失**

iOS `baiduFileList`（`:730`）+ `switchBaiduFile`（`:1516`）+ `playNextBaiduFile`（`:1619`）+ 预加载 `prefetchNextBaiduFile`（`:2578`）+ 缓存进度 `reportBaiduCacheProgressIfNeeded`（`:2495`）。Flutter **全仓 0 引用**。

## 1. 本轮新增（95 → 100 项）

### 🔴 F-P01 · 原生网盘播放链路（夸克/百度/UC）— P1

**问题**：见发现 B。`PanPlayer._guardChannel` 对原生盘直接抛错。

**开发步骤**：
1. 夸克原生链路：
   - 分享链接 → `CloudDriveManager.resolvePlayURL`（或等效）→ 获取文件列表 → 选集 → 解析直链（原画）→ 播放；
   - 原画 403/断连/首帧超时 → 自动切 m3u8 兜底（`switchToQuarkFallback`，并入 UI-F21）；
   - 线路偏好 `vbox_route=original/transcode`（F-P04）；
2. 百度原生链路：
   - 获取文件列表 → 多文件展示选集 → `startBaiduPlayback`；
   - Cookie 合并策略（F-P03）；
   - 本地代理 `baidu-stream`（18080）；
   - 缓存进度监听（F-P05）；
3. UC 原生链路：对齐 iOS `playUCEpisode`；
4. 接入详情页播放分支（详情页需识别网盘源并走 `PanPlayer`）。

**验收**：夸克/百度/UC 原生盘可播放；原画失败自动兜底；选集切换正常。

---

### 🔴 F-P02 · Node 托管盘播放链路零消费 — P1

**问题**：见发现 A。`PanPlayer` + `NodePanClient` 已建，但详情页/播放链路零消费。

**开发步骤**：
1. 详情页识别网盘源（`vod_play_url` 含 `$$$` 或分享链接格式）；
2. 调用 `PanPlayer.resolveShare` → 获取条目列表；
3. 展示文件列表（选集/多文件）；
4. 选择后 `PanPlayer.prepare` → 解析播放地址 → 缓存；
5. `PanPlayer.open` → 走 `PlaybackRoute.pan` 打开播放；
6. Node 未就绪时优雅降级（`NodePanException.nodeUnavailable` → 提示重启）。

**验收**：115/123/139/189/迅雷/光鸭/蜗牛/夸克Node/UCNode/百度Node 可播放；Node 未就绪有提示；缓存复用。

---

### 🔴 F-P03 · 百度网盘 Cookie 合并 + 本地代理流 — P2

**问题**：见发现 C。iOS 有完整 Cookie 合并策略；Flutter 有 `BaiduProxyTransport` 但未接入播放链路。

**开发步骤**：
1. 百度播放时合并 Cookie：`BaiduProxyTransport` 返回的 Cookie + 用户 BDUSS/STOKEN（`normalizeBaiduCookie`）；
2. 本地代理流 `baidu-stream`（`127.0.0.1:18080`）接入播放器内核选择（iOS `:1128/1211/1214/1217`：MDK 优先、排除 AliPlayer）；
3. 代理流兼容性判定（并入 R-01 兼容规则）。

**验收**：百度网盘播放带正确 Cookie；本地代理流可用；内核选择正确。

---

### 🔴 F-P04 · 夸克线路偏好（原画/普画）— P2

**问题**：见发现 D。iOS `quarkRoutePreference` + `vbox_route` 参数。

**开发步骤**：
1. 新增 `quarkRoutePreference` 字段（`original`/`transcode`）；
2. 解析时传入 `vbox_route` 参数（`PanPlayer.prepare` 或等效位置）；
3. 设置页新增「夸克线路偏好」选项（原画/普画/自动）；
4. 偏好持久化（契约键 `quark_route_preference`，如不存在则新增）。

**验收**：夸克播放可按偏好选择原画/普画；设置可配置；持久化生效。

---

### 🔴 F-P05 · 百度网盘多文件选集 + 缓存进度 + 预加载 — P2

**问题**：见发现 E。iOS 有完整多文件选集链路。

**开发步骤**：
1. 百度获取文件列表 → 展示多文件选集 UI（对齐 iOS 百度文件列表弹层）；
2. `switchBaiduFile`：切换文件时重新解析直链；
3. `playNextBaiduFile`：播放完自动下一文件；
4. 缓存进度监听：百度本地代理流下载进度 → UI 展示（`reportBaiduCacheProgressIfNeeded`）；
5. 预加载：`prefetchNextBaiduFile` + `prefetchNextBaiduFileNearEnd`（近结尾预取下一文件）。

**验收**：百度多文件可浏览选集；切换文件播放正常；缓存进度可见；近结尾预取下一文件。
