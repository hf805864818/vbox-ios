# vbox 遗漏待开发详细步骤方案 v1.21

> **版本**：v1.21 —— 在 [v1.20](computer:///workspace/docs/遗漏待开发详细步骤方案_v1.20.md)（15 项未开发 + 验收 3）基础上，记录 **Wave H（容量管理 + 取流增强）**：NC-清1 · 夸克空间清理 → NC-清2 · UC 空间清理 → NC-清3 · 阿里转存清理 → NC-清4 · UC TV Token 通道 → NC-清5 · Node 就绪自动 push + `wexfnwconfig.json` 兜底。
> **核对日期**：2026-10-06
> **数据源**：仓库代码（HEAD `2c22ff8` + 本批工作区改动）+ iOS 端 `CloudDriveManager.swift` / `ucNativeClient` / `AliyunPgPlayManager.swift` / `NodeCredentialSyncService.swift` + v1.20
> **核心原则（强制）**：UI 层一律以 iOS 端为准（35 张真机截图 + 54 个 Swift 源码）。

> **本轮要点**：
> 1. **容量管理补齐（NC-清1/2/3）**：夸克「分享来源」清理（容量低于阈值 → 删「来自：分享」目录 + 根目录视频，排除未过期转存缓存）、UC 转存文件删除、阿里转存延迟清理（内存队列 + 到期 `moveToTrash`，失败 ≤10 分钟重试），三者逐档对齐 iOS 判定与请求体。
> 2. **取流增强（NC-清4）**：UC **TV Token 通道**落地 —— `x-pan` 签名 + 设备指纹 + 原片直链（`GET /file?method=streaming`），档位优先于既有 `v2/play` → `download_url` 回退链；TV Token 过期（`errno=10001 && status=-1`）自动降级不中断。
> 3. **Node 兜底（NC-清5）**：Node 就绪**首次**自动推送本机凭据镜像（`hasAutoSynced` 去重）+ `pull` 并读 `wexfnwconfig.json`（覆盖 HTTP 读接口不暴露的 thunder / guangya / woniu4k）+ `deleteNodeCredential` 直改配置文件移除字段（防 DELETE 失败后 pull 复活登录态）。
> 4. **未开发项 15 → 10**（P0 **0** · P1 **2** · P2 **7** · P3 **1**）；验收项仍 3；**NC-清族（5 项）清零**。
> 5. **已登记差异**：① iOS 由 `NodeRuntimeManager` 单例在 Node 就绪通知中自动触发，Flutter 侧 Node 运行时宿主（**ND-01**，P0）尚未交付，故 NC-清5 以服务侧 API（`onNodeReady`）暴露，待 ND-01 交付后由启动编排/就绪事件调用，去重为实例级；② iOS `/ali-stream` 本地代理注入请求头，Flutter 直接以 `headers` 交付播放器（不建本地代理）；③ 阿里「方案C extscreen 刷新」由既有 `aliyun_extscreen_client.dart` 承载，ADrive 客户端只做官方/WebApp + `verifyAdriveToken`。

## 1. Wave H 交付记录（容量管理 + 取流增强）

### ✅ NC-清1 · 夸克空间清理（`quarkCleanShareOriginIfNeeded`） — 已交付

**问题**（v1.15 登记 · P3）：iOS 在播放分享链入口按容量阈值清理「来自：分享」目录与根目录视频，Flutter 侧未移植（头注登记 `quark_native_client.dart`）。

**落地口径**（对齐 iOS `CloudDriveManager.quarkCleanShareOriginIfNeeded`）：

- **容量检测**（[getQuotaInfo](file:///workspace/lib/data/datasources/remote/quark_native_client.dart#L767)）：`member` → `quota/info` 双端点取 `{used,total}`，换算剩余 GB；
- **阈值门限**（[cleanShareOriginIfNeeded](file:///workspace/lib/data/datasources/remote/quark_native_client.dart#L861)，`thresholdGb` 缺省 1.0，播放链以 2.0 调用 L698）：剩余 ≥ 阈值直接返回 0（不产生任何删除请求）；
- **目标收集**（[_collectFids](file:///workspace/lib/data/datasources/remote/quark_native_client.dart#L1021)）：删「来自：分享」目录（含子文件夹）+ 根目录视频文件；**排除未过期的转存缓存文件 ID**（与 iOS 一致，避免误删刚转存待播的文件）；
- **分批删除**（[_deleteFidsBatched](file:///workspace/lib/data/datasources/remote/quark_native_client.dart#L992)）+ **回收站彻底清理**（[deleteFiles](file:///workspace/lib/data/datasources/remote/quark_native_client.dart#L928)：等待删除任务落盘 → `recycle/list` → `recycle/remove`，尽力而为）。

**验收**：阈值门限 / 目标收集（排除缓存）/ 分批删除与回收站清理路径由既有 [quark_native_client_test.dart](file:///workspace/test/data/datasources/remote/quark_native_client_test.dart) 覆盖请求体与解析口径。

### ✅ NC-清3 · 阿里转存清理（`scheduleCleanup` + `processPendingCleanups`） — 已交付

**问题**（v1.15 登记 · P3）：iOS `AliyunPgPlayManager` 转存后按延迟清理临时文件，Flutter 侧未移植。

**落地口径**（对齐 iOS `scheduleCleanup(fileId:accessToken:)` / `processPendingCleanups` / `moveToTrash`）：
