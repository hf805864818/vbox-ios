## 0. 本轮播放器深扫 · 核心结论

### 🔴 最重磅发现：播放控制层全部构建完成，但**播放页整体不存在**

**证据链**：
1. `PlayerControlsView`（顶栏 + 底栏 + 进度条 + 6 面板 + 弹幕层）已构建 → 但**全仓零消费**（只在自身组件内部互相引用，无任何页面 mount 它）
2. `presentation/pages/player/` **目录不存在**
3. 详情页「立即播放」[detail_page.dart:204](file:///workspace/lib/presentation/widgets/detail_page.dart#L204) 只调 `controller.play()` 后 `_toast('开始播放')`，**无播放 UI 跳转**

**结论**：R-02 不只是「UI 未对齐」，而是**播放页根本还没落地**——C-02/C-03/C-04 批次交付的是一堆**未挂载的组件**。此项升为 **P0 最优先**。

## 1. 本轮新增（80 → 85 项）

### 🔴 UI-F6 · 播放器工具快捷菜单（ToolsQuickMenu 是 stub 占位）— P1

**问题**：Flutter `player_controls_view.dart:270-280` 的「更多」菜单是**硬编码占位**：

```dart
child: const Text('投屏 / 播放设置（后续批次接入）'),
```

而 iOS `ToolsQuickMenuV2:10600` 有完整 **8 项快捷开关**：
| iOS 菜单项 | 类型 | Flutter 现状 |
|---|---|---|
| 长按倍速（跳转） | Button → 面板 | ❌ 无 |
| 跳过片头片尾 | Button → 面板 | ❌ 无（UI-F2） |
| 弹幕搜索 | Button → 面板 | ❌ 无（UI-F3） |
| 字幕设置 | Button → 面板 | ❌ 无（UI-F5） |
| 自动连播 | Toggle | ❌ 无 |
| 后台播放 | Toggle | ❌ 无 |
| 画中画 | Toggle | ❌ 无 |
| 调试浮层 | Toggle | ❌ 无 |

**开发步骤**：
1. 新建 `ToolsQuickMenuPanel`（对齐 iOS `ToolsQuickMenuV2` 形态：磨砂/深色背景 + 行项 + 开关）；
2. 4 个跳转项：跳过片头片尾 / 弹幕搜索 / 字幕设置 / 长按倍速 → 各自面板（UI-F2/F3/F5 + S-07）；
3. 4 个开关项：自动连播 / 后台播放 / 画中画 / 调试浮层 → 状态持久化 prefs；
4. 面板互斥逻辑接入 `PlayerControlsController._openOnly`；
5. 对齐 iOS 磨砂皮肤适配（`usesFrostedSkin` → Flutter 皮肤判别）。

**验收**：菜单 8 项全部可用；开关状态持久化；磨砂皮肤下配色正确；面板形态与 iOS 一致。

### 🔴 UI-F7 · 弹幕发送功能（输入框是静态装饰）— P1

**问题**：Flutter `player_bottom_bar.dart:192-215` 的 `_DanmakuInputPill` 是**静态 `Container`**，写死文案「请文明发送弹幕」，**无 `TextField`、无提交、无发送链路**。iOS `PlayerViewsV2:2047` 有完整 `sendDanmaku(text:)` + `TextField`（`:7210`）+ `LogVarDanmakuService.shared.sendDanmaku`（`:2096`）。

**开发步骤**：
1. 底栏弹幕输入改真实 `TextField`（点击弹出输入键盘或底部弹层，对齐 iOS `danmakuInputFocused` 焦点态）；
2. 新建发送链路：`DanmakuController.send(text)` → 平台弹幕服务；
3. 发送成功/失败 toast 反馈；
4. 发送后自身弹幕即时上屏（本地回显）；
5. 竖屏也补弹幕输入入口（iOS 横竖均有，Flutter 仅横屏占位）。

**验收**：可输入并发送弹幕；发送后本地回显；失败有提示；横竖屏均可用。

### 🔴 UI-F8 · 横屏锁定未接线 — P1

**问题**：`player_controls_view.dart:77-78` 硬编码 `showLock: false` + `locked: false`，`onToggleLock` 未传入；`PlayerControlsController.onToggleOrientationLock`（L123）定义但零调用。iOS `OrientationHelper.lockOrientation(.landscape)`（`:7711`）+ `unlockOrientation()`（`:8372`）。

**开发步骤**：
1. 播放器全屏/横屏时传 `showLock: true`；
2. `onToggleLock` 接 `PlayerControlsController.onToggleOrientationLock`；
3. 锁定后：隐藏其余控制元素（iOS 锁定态只留解锁按钮）、禁止旋转、锁定时长按/手势按 iOS 语义处理；
4. 锁定时 `locked: true` 高亮显示。

**验收**：横屏锁定按钮可点；锁定后禁止旋转；解锁恢复；与 iOS 行为一致。

---

### 🔴 UI-F9 · 控制栏自动隐藏（含锁定按钮独立隐藏）— P1

**问题**：iOS `PlayerViewsV2:6796` 有 `autoHideTask`（3 秒无操作隐藏控制栏）+ 锁定按钮**独立**自动隐藏（`:6850`，与主控制栏解耦）；Flutter 全仓 **0 引用**。

**开发步骤**：
1. 播放器加 `_autoHideTimer`（3 秒无操作 → 隐藏顶栏/底栏/进度条）；
2. 任意交互（点击/拖动/手势）重置计时；
3. 播放中隐藏、暂停时常显（对齐 iOS `showControls` 语义）；
4. 锁定按钮独立计时（与主控制栏解耦，对齐 iOS 注释「锁定按钮独立自动隐藏（3秒）」）；
5. 面板打开时暂停自动隐藏（`hasAnyPanelOpen` 守卫）。

**验收**：3 秒无操作控制栏隐藏；点击恢复；暂停时常显；锁定按钮独立隐藏；面板打开时不隐藏。

### 🔴 UI-F10 · 播放器错误态 / 重试视图 — P1

**问题**：iOS `ErrorView`（`:7557`）+ `ErrorViewWithLogs`（`:7614`，含 `debugLogs` + `onRetry`）+ `CompatibilityUnavailableView`（`:8907`）；Flutter 播放器**无任何错误视图**。

**开发步骤**：
1. 新建 `PlayerErrorView`（错误图标 + 原因文案 + 「重试」按钮）；
2. 新建 `PlayerErrorWithLogsView`（在错误态基础上加可展开调试日志，对齐 iOS `ErrorViewWithLogs`）；
3. 新建 `PlayerUnsupportedView`（内核不支持/编码不兼容，对齐 `CompatibilityUnavailableView`）；
4. 接入 `PlayerController` 错误流（`nodeNotReady`/播放失败/解析失败分类文案，对齐 iOS 多分支错误文案）；
5. 重试按钮接 `controller.retry()`。

**验收**：播放失败显示错误视图；重试可恢复；可展开日志；不支持编码显示兼容提示。

### 🟡 UI-F11 · 旋转辅助 OrientationHelper — P2

**问题**：iOS `OrientationHelper`（`:27`）提供 `rotateToLandscape()`/`lockOrientation()`/`allowAllOrientations()`/`unlockOrientation()`；Flutter 无 `SystemChrome.setPreferredOrientations` 方向控制。

**开发步骤**：
1. 新建 `OrientationHelper`（`SystemChrome.setPreferredOrientations` 封装）；
2. 接口：`rotateToLandscape()`/`rotateToPortrait()`/`lockOrientation()`/`allowAll()`；
3. 详情页「立即播放」→ 自动横屏（对齐 iOS `:639`）；
4. 播放页退出 → 恢复竖屏（对齐 iOS `:696`）；
5. 与 UI-F8 锁定联动。

**验收**：进入播放自动横屏；退出恢复竖屏；锁定可禁止旋转。

---

### 🟡 UI-F12 · 视频标题滚动（VideoNameScrollingText）— P3 观察项

**问题**：iOS `VideoNameScrollingText`（`:7879`）长标题跑马灯滚动；Flutter 顶栏 `TextOverflow.ellipsis` 截断。

**处置**：记观察项，随 R-02 播放页落地时按 iOS 形态评估（若无超长标题场景可不做）。

---

### 🟡 UI-F13 · 弹幕渲染对象池 — P3 观察项

**问题**：iOS `DanmakuLayerPool`（Ext:198，复用 `CATextLayer`，`maxPoolSize = 60`，每帧不新建）；Flutter `DanmakuOverlay` 用 `Stack + Positioned`（每帧 widget 重建）。渲染机制不同，Flutter 依赖框架 layer 复用，**未必劣化**。

**处置**：记观察项，R-02 落地后按实测帧率决定是否引入 `RepaintBoundary`/自定义 render object 优化。
