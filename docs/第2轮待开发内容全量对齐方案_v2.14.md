## 0. 本轮最深发现：播放器依赖层与数据链路

### 🔴 发现 A：`pubspec.yaml` **无任何播放器依赖**

[pubspec.yaml](file:///workspace/pubspec.yaml) 实测：**无 `media_kit` / `video_player` / `fvp` / `just_audio` / `audio_service`**。播放器**全靠 MethodChannel 原生桥**（`com.vbox.player/player`）。

原生侧脚手架确实齐全（非纯空缺）：
`android/.../PlayerPlugin.kt` · `player/CodecCapability.kt` · `player/MediaPlaybackService.kt` · `BackgroundPlayPlugin.kt` · `macos/Runner/PlayerPlugin.swift` · `windows/runner/player_plugin.cpp`

**含义**：R-01 内核矩阵不是「未对齐」，而是**完全依赖原生侧实现**——Flutter 侧只做控制面 + 降级链，渲染/解码须各端原生补齐。此项并入 R-01 证据。

### 🔴 发现 B：**弹幕数据服务完全缺失**（不只是面板）

Flutter 弹幕只有三块：`DanmakuPlaybackController`（仅 `hasMore`/`reset` 游标）+ `danmaku_parser.dart`（解析）+ `danmaku_lane_engine.dart`（排布）。**`matchEpisode`/`fetchDanmaku`/`sendDanmaku` 全仓 0 引用**。

iOS `LogVarDanmakuService` 是完整数据链路：
- `matchEpisode(fileName:)` → 番剧匹配 episodeId（`:1866`）
- `manualLoadDanmaku(episodeId:)` → 手动加载（`:1885`）
- `fetchDanmaku(episodeId:)` → 拉取弹幕（`:1895`）
- `sendDanmaku(episodeId:content:)` → 发送（`:2047`）

**含义**：v2.13 的 UI-F3（搜索面板）/ UI-F7（输入框）都只是**壳**——底层**没有数据服务**。这是弹幕功能最大的空缺。

### 🔴 发现 C：`HistoryUseCases.recordProgress` **零调用**——进度不落库

[app.dart:209](file:///workspace/lib/app.dart#L209) 已装配 `HistoryUseCases`，profile/library 页读取 `recent`，但**写入 `recordProgress` 在播放链路零调用**（播放页不存在 → 进度无上报）。iOS 有「播放自动 seek 到上次进度」（网盘 `:4187` / 普通 `:6531` / MPV `:9098`，且 `resume > 10` 才 seek）。

**含义**：观看记录不更新、无续播。属播放页 R-02 的必备子能力。

## 1. 本轮新增（85 → 89 项）

### 🔴 UI-F14 · 弹幕数据服务（番剧匹配 / 拉取 / 发送）— P1

**问题**：见发现 B。Flutter 弹幕**无数据服务层**。

**开发步骤**：
1. 新建 `DanmakuService`（对齐 iOS `LogVarDanmakuService`）：
   - `matchEpisode(fileName)`：按文件名匹配番剧 episodeId；
   - `fetchDanmaku(episodeId)`：拉取弹幕列表 → 喂 `DanmakuPlaybackController`；
   - `sendDanmaku(episodeId, content)`：发送弹幕；
2. 接入弹幕源 API（对齐 iOS 弹幕服务端点）；
3. 自动匹配：播放开始时按文件名匹配 episodeId（对齐 iOS `:1866`）；
4. 手动加载：接 UI-F3 弹幕搜索面板的 `onLoadDanmaku` 回调（iOS `:7377`）；
5. 发送：接 UI-F7 弹幕输入；
6. 无匹配时优雅降级（无弹幕，不报错）。

**验收**：播放自动匹配并加载弹幕；可手动指定番剧加载；可发送弹幕；发送后回显。

### 🔴 UI-F15 · 媒体会话 / 锁屏控制（Now Playing / MediaSession）— P1

**问题**：iOS 用 `MPNowPlayingInfoCenter` + `MPRemoteCommandCenter`（锁屏显示 + 锁屏/耳机线控 + 后台播放控制）。Flutter **无 `audio_service` 依赖、无 NowPlaying 实现**；`music_player.dart:10` 注释明确：「歌词 / NowPlaying / 锁屏控制属平台」——**已登记但未做**。

**含义**：即使 S-07 的后台播放接线，**也没有锁屏控制**——用户切后台后无法从锁屏/通知栏控制播放。

**开发步骤**：
1. 引入媒体会话方案（Android `MediaSession` + 通知栏；桌面端 no-op）；
2. 实现 Now Playing 元数据（标题/封面/时长/进度，对齐 iOS MPNowPlayingInfoCenter）；
3. 注册远程控制命令（播放/暂停/上一集/下一集/进度，对齐 MPRemoteCommandCenter）；
4. 与 `BackgroundPlayController`（S-07）联动；
5. 音乐播放器同步接入（`music_player.dart` 待办项）。

**验收**：锁屏显示播放信息；锁屏/通知栏可控制播放；切集同步；音乐同享。

### 🔴 UI-F16 · 播放进度记录 + 续播 seek — P1

**问题**：见发现 C。`HistoryUseCases.recordProgress` **零调用**；播放器**无「读取上次进度并 seek」**。iOS 三处自动续播（`:4187`/`:6531`/`:9098`，`resume > 10` 守卫）。

**开发步骤**：
1. 播放中定时上报进度 → `HistoryUseCases.recordProgress`（对齐 iOS 进度上报节流）；
2. 播放开始读取历史进度 → 若 `resume > 10s` 自动 seek（对齐 iOS 守卫条件）；
3. MPV/网盘/普通三条播放路径均接入（对齐 iOS 三处）；
4. 播完清除进度（对齐 iOS 完成态语义）；
5. 历史列表续播入口（library_views 已有入口）打通到播放页定位。

**验收**：播放进度落库；重进自动续播（>10s 才 seek）；播完重置；历史续播入口可用。

---

### 🟡 UI-F17 · 网盘下一集预加载 — P2

**问题**：iOS `prefetchNextBaiduFile`（`:2578`）+ `prefetchNextBaiduFileNearEnd`（`:4392`，近结尾预告下一集）——百度网盘大文件近结尾预取，提速无缝切集。Flutter **0 引用**。

**开发步骤**：
1. 网盘播放器近结尾（如剩余 30s）触发下一集预取（对齐 iOS `NearEnd` 时机）；
2. 预取复用 `pan_player` 解析链路，缓存下一集直链；
3. 切集时命中缓存直接播放；
4. 非网盘源不启用（对齐 iOS 范围）。

**验收**：网盘近结尾预取下一集；切集无等待；非网盘源无影响。

### 🔴 R-01 细化 · 内核兼容判定规则不完整 — 并入 R-01（P0）

**问题**：iOS `nodeCompatibilityReason`（`:1314`）有 **13 条规则**（MKV/FLV/AVI/RMVB/HEVC/H265/x265/10bit/HDR/DDP/EAC3/DTS/TrueHD/Atmos）+ `hardUnsupportedContainers`（ISO/M2TS 等硬不支持容器）；Flutter 侧 `player_controller.dart:55` 仅简化 `needsFallback`，Android `CodecCapability.kt` 仅 **2 条**（mkv→VLC、hevc 硬解检测）。

**开发步骤**：
1. 补全 `CodecCapability` 规则集（13 条容器/编码 + 硬不支持容器）；
2. 对齐 iOS「只认系统内核明确不支持」策略（避免误判仅含 4K 的 MP4）；
3. 网盘无扩展名 URL 按真实文件名判定（对齐 iOS `:1312` 注释）；
4. 判定结果驱动内核选择（R-01 降级链）。

**验收**：规则集与 iOS 对齐；MKV/HEVC/10bit 等正确走兼容内核；MP4/4K 不误判。

## 2. 本轮排除的疑点（验证后确认非遗漏）

| 疑点 | 核实结论 |
|---|---|
| **音轨切换** | iOS 的「音轨」出现在 `:1326-1330`，是**兼容性判定规则输入**（DDP/DTS/TrueHD/Atmos → 判定是否需兼容内核），**非音轨选择器** → 不算遗漏 |
| **播放中线路切换** | 两端均在**详情页 / 解析层**处理（Flutter `detail_page` 线路 chips）；iOS 播放内的线路切换是**网盘内部兜底**（Quark fallback）→ 播放器 UI 无独立线路功能，非遗漏 |
| **内核依赖缺失** | 原生插件脚手架齐全（6 文件），非纯空缺 → 计入 R-01 证据而非新增项 |
