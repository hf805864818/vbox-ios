# vbox 遗漏待开发详细步骤方案 v1.17

> **版本**：v1.17 —— 在 [v1.16](computer:///workspace/docs/遗漏待开发详细步骤方案_v1.16.md)（30 项未开发 + 验收 3）基础上，记录 **Wave C（体验链）全批交付**：L-壳2 · 启动编排 → G-音1 · 音乐页/全屏播放器 → G-音2 · MiniPlayer 全局挂载 → L-壳1 · 品牌闪屏。
> **核对日期**：2026-10-05
> **数据源**：仓库代码（HEAD `7114152` + Wave C 工作区改动）+ iOS 源码（`vbox/Views/VboxSplashView.swift` · `vbox/Views/MusicView.swift` · `vbox/Views/MusicPlayerViews.swift` · `vbox/Services/SplashGateMonitor.swift` · `vbox/App/ContentView.swift`）+ v1.16
> **核心原则（强制）**：UI 层一律以 iOS 端为准（35 张真机截图 + 54 个 Swift 源码）。

> **本轮要点**：
> 1. **体验链贯通**：冷启动由「白屏转圈」改为「品牌渐变底 → 品牌闪屏动画 → 数据门控淡出进首页」，并对齐 iOS 的 **3.5s 最短展示 + 首页数据就绪信号 + 10s 兜底** 三条件门控。
> 2. **启动顺序编排落地**：按 iOS 冷启动口径编排 **会话恢复 → 远程源同步 → 引擎就绪**，每步独立收敛，**单步失败降级不阻断**、可观测（`startup` 日志）。
> 3. **音乐续段闭环**：个人中心「网络音乐」由 Toast 占位改为真实音乐首页（五平台歌单/榜单/搜索）；新增全屏播放器（封面/进度/控制/队列/歌词）与播放队列弹层；MiniPlayer 在首页外壳全局挂载并支持展开全屏。
> 4. **未开发项 30 → 26**（P0 **0** · P1 **3** · P2 **15** · P3 **8**）；验收项仍 3。
> 5. **附带修复**：品牌闪屏字标在真实品牌字体下自然宽度 ≈217.6pt、超出 iOS 聚合宽度 182.2pt 造成 `RenderFlex` 溢出——改用等比缩至贴合，并新增真字体回归守卫测试。

## 1. Wave C 交付记录（体验链）

### ✅ L-壳2 · 启动编排 — 已交付

**问题**（v1.15 登记）：初始化完成后直接置位进首页，**无启动门控/编排**（远程源同步、引擎预热、会话恢复的顺序与失败处理未编排）。

**落地口径**（对齐 iOS 冷启动 `VBoxApp.swift` init + `ContentView.swift` onAppear）：
- 新增 [StartupOrchestrator](file:///workspace/lib/presentation/shell/startup_orchestrator.dart)：以 [StartupTask] 列表顺序执行，每步 `try/catch` 收敛为 [StartupStepResult]；
- 编排顺序：**① 会话恢复**（音乐队列 `MusicPlayerController.restore`，对齐 iOS `AudioPlayerManager.restoreQueue`）→ **② 远程源同步**（`RemoteSourceUseCases.refresh` 按 TTL 预热清单）→ **③ 引擎就绪**（D6 JS 引擎探测：JSC 主 / QuickJS 降级位，降级可观测）；
- **失败降级不阻断**：单步失败仅记 `error` 日志并继续，编排结束照常进首页；[StartupReport.allOk] / `failedSteps` 供观测。

**验收**：冷启动一次编排完成；单步失败不阻塞进入首页且有日志 —— 由 [startup_orchestrator_test.dart](file:///workspace/test/presentation/shell/startup_orchestrator_test.dart) 覆盖。

### ✅ G-音1 · 音乐页与全屏播放器 — 已交付

**问题**（v1.15 登记）：仅有控制器 + 队列存储 + MiniPlayer 组件；无音乐页、无全屏播放器；个人中心「网络音乐」为 Toast 占位。

**落地口径**（对齐 iOS `MusicView` / `MusicPlayerViews` / `MusicQueueSheet`）：
- **音乐首页** [music_home_page.dart](file:///workspace/lib/presentation/pages/music/music_home_page.dart)：平台选择（网易云 / QQ / 酷狗 / 酷我 / 咪咕）、歌单广场、排行榜、搜索；数据层 [music_playlist_service.dart](file:///workspace/lib/data/datasources/remote/music_playlist_service.dart) 移植 iOS `MusicPlaylistService`；
- **全屏播放器** [music_player_page.dart](file:///workspace/lib/presentation/pages/music/music_player_page.dart)：渐变背景、顶栏、封面、标题、进度条拖拽、播放控制、队列/歌词切换、下拉关闭手势、歌词解析显示；

> **落地差异（如实登记）**：音乐数据源以 vbox 统一数据接口（`vbox-ai.github.io/api/sources/manifest.json` 体系）为准，Flutter 端按 iOS 展示口径对齐；iOS 原服务的内嵌平台爬取细节不做逐行等价移植。

**验收**：可从入口进音乐页并播放；全屏播放器可用。
