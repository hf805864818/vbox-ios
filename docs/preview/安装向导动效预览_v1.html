方案 A · 品牌流光（深色）

  • 与 App 启动页同源的深色渐变底
  • Logo 呼吸缩放 + 流光扫过 + 发光投影
  • 进度条渐变填充 + 内部流光 + 外发光
  • 推荐：与 App 视觉最统一，实现成本最低

方案 B · 星环粒子（深色）

  • Logo 外双层旋转星环（粒子感）
  • 视觉冲击更强，科技感
  • 进度条圆角胶囊 + 发光
  • 适合强调「引擎/科技」定位

方案 C · 现代浅色

  • 浅色底 + 玫瑰红点缀，干净
  • 与 Windows 浅色主题更协调
  • 进度条与步骤卡阴影更轻
  • 适合白天/浅色系统偏好用户
说明：以上为纯前端动效原型（HTML/CSS），仅用于确认视觉方向。
选定方案后我再给「如何在 Inno Setup 落地」的实施方案（不同方案的落地难度差别较大，见下一步说明）。
