## 2. 新发现遗漏明细（★4 新增 + 2 细化）

### 2.1 PF-01-MAC · macOS entitlements 权限缺失（P0，半小时级修复但 Release 全挂）

**现状实码证据**：

| 文件 | 现有键 | 缺失键 | 后果 |
|---|---|---|---|
| `macos/Runner/DebugProfile.entitlements` | app-sandbox / cs.allow-jit / network.**server** | **network.client** | Debug 版外网请求被沙盒拦（raw.githubusercontent / 源站全不可达） |
| `macos/Runner/Release.entitlements` | **仅 app-sandbox** | **network.server + network.client + cs.allow-jit 全缺** | Release 版：①Node 58080 / lx 58083 / go-proxy 本地监听全被拦；②所有外网请求被拦；③QuickJS FFI / Node JIT 被禁（`cs.allow-jit` 缺失 → 引擎崩溃） |

**对照总方案**：§4.8「macOS 需关闭沙盒网络限制或申请 entitlement：沙盒下 localhost 监听需 `com.apple.security.network.server`」——Flutter 模板默认生成的 entitlements 从未按 vbox 架构补全。

### 2.2 RT-01 · Python 运行时分发（P2，v2.x 清单历史性缺项）

- **总方案决策**（§2.5 / §4.3）：Android = **Chaquopy**（Gradle 依赖，零 NDK）；Windows = **CPython 官方发行版**；iOS = 自编译 3.14.7 + 静态 lxml（不移植）；三端差异用 Spider ABI 屏蔽。
- **现状**：`python_bridge_engine.dart` 以 `Process.start('python3', ...)` 启动子进程——**桌面端**（Windows/macOS 开发机）可用；**Android 系统无 python3 二进制** → 9 个 `y_*` Python 蜘蛛站在 Android 全部 `E_RUNTIME`。
- **遗漏定性**：v2.1~v2.4 的 45→51 项清单从未包含「Python 运行时分发」域（ND-01 只覆盖 Node）。这是总方案 §4.3 标注「重大成本项」的领域。

### 2.3 ND-02 · Node bundle 按需下载与更新（P1）

- **总方案**（A.8-3 / E6 / 4.2）：`kstore_index.js` 远程 **6.4 MB**（内置 3.9 MB），**按需下载而非内置**；`nodeRuntimeBundle`/`nodeRuntimeBundleVer`（kstore.version）两清单条目支撑版本比对；MD5 校验失败 → 回退 App Bundle 内置。
- **现状**：`remote_source_config_manager.dart:310-316` 已读取 bundleUrl / bundleVer（清单解析层就绪），但**无「下载 → MD5 比对 → 与已装版本比对 → 落盘安装 → 失败回退内置」链路**；v2.2 ND-01 步骤 5 只写「内置 noderuntime/ 随包分发」——把 6.4MB 打进包体会显著增大三端安装包。

### 2.4 ND-03 · lx 插件分发与加载（P2）

- **总方案**（A.3 / A.4）：`sources/lx/` 两插件（`daxe.js` 17KB / `nianxin.js` 26KB）；`SiteConfig` 扩展字段 `pluginPath`/`version`/`md5` 用于远程更新比对。
- **现状**：`resolve_site_mode.dart:49-50` 有 `nodejs_musicaidaxe→daxe` / `nodejs_musicainianxin→nianxin` 模式映射；`backup_service.dart:220` 有 `lxPlugins` 备份字段；`site_config.dart` 已建模 `pluginPath` 等字段——但**无插件文件下载/安装到 `plugins/lx/` 目录/版本更新比对**链路。音乐模块（G 族）的 Node 托管音乐源依赖此通路。

### 2.5 ND-01 细化 · 5 端口矩阵 + 崩溃恢复（并入既有项）

v2.2 ND-01 只写「监听 58080；LX 58083；健康检查」。按总方案 4.2 补全：

| 端口 | 用途 | 补充要求 |
|---|---|---|
| 58080 | mainPort（kstore bundle 主端口） | 已列 |
| **2333** | catpawPort（catpaw bundle，**可选启用**） | 未列 |
| **58082** | healthPort（健康探测） | 心跳周期 HTTP 探测 → 连续失败判崩溃 → 自动重启 |
| 58083 | lxPort（lx-music 桥接） | 已列 |
| **58084** | lxHealthPort（lx 桥健康） | 未列 |

**崩溃恢复三件套**（总方案 4.2）：① 周期心跳 → 崩溃自动重启；② **内存告警 → 降级（卸载非必要 bundle）**；③ bundle MD5 校验失败 → 回退内置资源（与 ND-02 合并实施）。
**握手文件**（`.startup.ack` / `.relisten` / `.relisten.ack` / `.lx.ack`）：iOS NodeMobile 挂起恢复特化（App 切后台冻结进程需 relisten），Flutter 独立进程无挂起语义 → **登记为不移植**（NS-16：`.relisten` 系列免做；`.startup.ack` 就绪语义由 healthPort 心跳等价替代）。

### 2.6 O-04 细化 · minAppVersion 兼容门控（并入既有项）

总方案 A.2：manifest 的 `minAppVersion` 做客户端兼容门控（旧版本客户端不解析新清单结构）。现状：`remote_manifest.dart` 解析 `disabledKeys`/`configVersion`/`ttlSeconds` 均有，**minAppVersion 无消费**——旧客户端遇新清单 schema 变更会解析崩溃而非优雅降级。

## 4. 新增项详细开发步骤（★本版新增）

### PF-01-MAC macOS entitlements 补全（P0，先行收——半小时级）
1. `macos/Runner/Release.entitlements` 增三键：`com.apple.security.network.server`（Node 58080/lx 58083/go-proxy 监听）、`com.apple.security.network.client`（全部外网请求）、`com.apple.security.cs.allow-jit`（QuickJS FFI / libmpv JIT）。
2. `macos/Runner/DebugProfile.entitlements` 补 `com.apple.security.network.client`（已有 server+jit）。
3. CI build-macos 编译验证 + 真机 Release 构建冒烟（Node 桥起一个 `/spider/` 请求 + 外网拉一次 manifest）。
4. 登记入 PF-01 平台能力配置核销表（macOS 列）。
- **验收**：Release 构建下 Node 桥 58080 可达、manifest 拉取成功、QuickJS 引擎不崩溃。

### ND-02 Node bundle 按需下载与更新（P1）
1. `NodeBundleStore`：本地 `noderuntime/bundles/` 目录管理（当前版本号 + MD5 清单）。
2. 启动编排（L-05-3）顺序：读 manifest `nodeRuntimeBundleVer` → 与本地版本比对 → 不一致才经代理降级链下载（6.4MB，进度可观测）→ MD5 校验 → 落盘 + 更新记录。
3. 校验失败 / 下载失败 → **回退 App Bundle 内置 3.9MB**（随包资源，总方案 4.2 口径）。
4. 内存告警降级钩子（与 ND-01 细化项合并）：收到系统内存告警 → 卸载非必要 bundle。
- **验收**：首装不重复下载；远程 bundle 升版后自动更新；MD5 篡改 → 回退内置且 Node 站仍可用。

### RT-01 Python 运行时分发（P2）
1. Android：`build.gradle.kts` 引 **Chaquopy**（Gradle 依赖零 NDK，总方案已评估）；Python 脚本 + 依赖（`lxml` 走 Chaquopy 的 pip 构建管道）打包进 APK。
2. Android：`PythonBridgeEngine` 增加「可执行文件定位」抽象——优先 Chaquopy `Python.start()` 入口，等价注入 `pythonExecutable`；无 Python 时站点解析为 `E_RUNTIME` 并在 UI 标注「该源需要 Python（此端不支持）」。
3. Windows：首启检测系统 `python3`/`python`（PATH 探测）→ 缺失则引导安装 CPython 官方发行版（lxml 用官方 wheel，无需自编译，总方案 4.3 口径）。
4. macOS：系统自带 python3（`python_bridge_engine` 现状即可），登记免做。
5. Spider ABI 不变（输入/输出 JSON 屏蔽三端差异，总方案 4.3 结论）。
- **验收**：Android 真机跑通 1 个 y_* 站 5 op；Windows 无 python 环境有引导；9 站在桌面端回归通过。

### ND-03 lx 插件分发加载（P2，G 族音乐前置）
1. `LxPluginStore`：`noderuntime/plugins/lx/` 目录管理（文件 + `version`/`md5` 记录）。
2. 站点解析命中 `engineType == 'lxMusic'`（`resolve_site_mode` daxe/nianxin 映射已有）→ 检查本地插件 → 缺失则按 `pluginPath` 经代理降级链下载 → `version`/`md5` 比对更新。
3. lx 桥（58083）启动时加载插件目录（对齐 iOS `NodeRuntimeManager` 语义）。
4. 备份 `lxPlugins` 字段（已有）↔ 恢复时写回插件目录。
- **验收**：音乐模块两个 lx 站（daxe/nianxin）在插件缺失时自动补齐并可用；远程插件升版后自动更新。

### 细化项步骤（并入既有条目）
- **ND-01**：步骤 2 改为「5 端口矩阵（58080/2333/58082/58083/58084）」；步骤 3 启动编排增「58082 心跳周期探测 → 连续 N 失败自动重启 + 内存告警降级」；登记 **NS-16**（`.relisten` 系列握手不移植：iOS NodeMobile 挂起恢复特化，Flutter 独立进程无此语义；`.startup.ack` 就绪语义由心跳等价）。
- **O-04**：步骤补「manifest 解析后校验 `minAppVersion` > 当前版本 → 保留缓存清单 + 日志告警，不应用新 schema」。
