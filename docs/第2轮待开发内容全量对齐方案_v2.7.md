## 1. 新发现 UI 差异明细

### 1.1 UI-A1a · 首页顶栏结构不一致（图1 实测）

| 元素 | iOS 参考图（vbox首页主页面.PNG） | Flutter 现状（home_page.dart L116-135） | 差距 |
|---|---|---|---|
| 左侧 | **九宫格图标**（分类/频道入口） | ❌ 无 | 缺 |
| 中间 | **搜索框**（浅灰圆角 + 放大镜 + 占位「搜索影片、剧集」） | ❌ 无（仅 AppBar `title` 文本） | 缺 |
| 右侧 | **三图标：排行榜（柱状图）/ 历史记录（时钟）/ 快速入口（闪电）** | ⚠️ 仅 2 个：切换源 + 搜索 | 缺排行/历史/闪电；「搜索」为图标非搜索框 |

> iOS `MainViews.swift` HomeView 顶部结构源码对应；Flutter 现 AppBar 仅「切换源」「搜索」两个 `IconButton`。

### 1.2 UI-A1b · 首页内容结构不一致

| 区块 | iOS 参考图 | Flutter 现状 | 差距 |
|---|---|---|---|
| Banner 轮播 | ✅ 7 指示器 + 片名左下角叠加 + 2.35:1 | ✅ `_DoubanBanner`（海报+底部标题遮罩+页码指示） | 基本对齐 |
| **快捷分类四胶囊** | ✅「🎬电影 / 📺剧集 / 🎭综艺 / 🏆榜单」单行四胶囊（带彩色图标） | ❌ 无 | 缺 |
| **栏目结构** | ✅「影院热映」「即将上映」等（A9 记 iOS 14+ 栏目；卡片 **2:3 竖版海报 + 黄色五角星评分角标「6.0」+ 底部片名**） | ⚠️ `feed.sections` 仅 **4 栏目**（热门电影/剧集/综艺/动漫） | **栏目标题与数量不一致**；评分角标待验证 |

## 3. UI 族详细开发步骤（★本版新增）

### UI-A1 首页结构对齐（P1）

1. **顶栏**（home_page.dart L116-135）：AppBar 改自定义顶栏——左：九宫格 `IconButton`（跳分类聚合页）；中：搜索框容器（浅灰圆角 r20 + 放大镜 + hint「搜索影片、剧集」，点按跳 search_page）；右：三图标（排行榜→douban_ranking、历史→观看记录页、快速入口→预留）。「切换源」入口移入九宫格页或保留为左上长按（对照 iOS HomeView 源码确认交互归属）。
2. **快捷分类四胶囊**：Banner 下新增单行四胶囊（带彩色 SF 风图标 + 文案），分别跳 douban 分类页（电影/剧集/综艺/榜单→ranking）。复用 `VboxChip` 选中态规格（`#34C759` + 同色描边 70%——对照 iOS 图实测为白底灰字带彩色图标，非选中态样式）。
3. **栏目矩阵**：`DoubanUseCases.homeFeed` 扩展 section 生成——对齐 iOS「影院热映 / 即将上映 / 热门剧集 / …」14+ 栏目口径（从 iOS `MainViews.swift` HomeView 栏目清单采样）；`DoubanSubjectCard` 补评分角标（黄色五角星 + 分数，右上角）与 2:3 竖版比例核验。
4. 分区标题头补右侧箭头 ›（可点进聚合页，44pt 触控区）。
5. Golden：home_portrait 重登基线（含四胶囊 + 评分角标态）；SSIM 相对门禁照常。
- **验收**：对照图1 逐项打勾（顶栏 5 元素 / 四胶囊 / 栏目标题与 iOS 一致 / 评分角标可见）；无源时不报错保持豆瓣（A9 回归）。

### UI-A2 视觉配对补全 12 族（P1，与页面族开发并行）

1. **立即入对**（golden 已有或页面已交付）：douban_ranking（golden 已有，补 pairing 行）→ 详情页 / 搜索空态 / 搜索结果 / 切换源浮层 / 切换源分类 / 网盘排序 / 直播 / 短剧 / 福利入口——逐页按 `visual_pairs.json` 模板追加（`--update-baseline` 登记实测分）。
2. **随批次入对**：播放器横竖屏（R-02 交付时，12 张参考图作还原点清单：顶部 PiP/音量/耳机/全屏/更多 + 左中锁定 + 底部双弹开关/弹幕输入胶囊/1x/蓝光/选集/内核「自动/MDK」）；网盘授权页（S-02）。
3. **CI**：`visual_regression.py` 对新增 pairing 自动生效（C1 相对门禁机制已就绪）。
- **验收**：`visual_pairs.json` 覆盖 19/19 族（播放器/网盘授权可标 `pending` 挂批次）。

### UI-A3 低分页排查（P1）

1. **douban_ranking（0.254）**：先补入 pairing（当前 golden 存在但未登记）；再对照「豆瓣排行榜页面.PNG」逐项核——榜单类型切换（TOP250/周榜/新片等标签行）、排名序号样式、海报尺寸比例、分区头。找出结构级差异修复后重登基线。
2. **welfare_settings（0.363）**：对照图 19（福利专区设置）：平台清单行（图标+名称+开关）逐行核；确认 golden 渲染无字体方块干扰。
3. **home（0.449）**：随 UI-A1 修复后重登；同时给 golden 测试注入固定假数据（避免空态假性低分——测试渲染无网络）。
4. 每页修复后跑 `--update-baseline` 登记 + CI 绿。
- **验收**：三页 SSIM 提升至 0.6+ 或书面登记「渲染环境差异不可再缩」的原因说明。
