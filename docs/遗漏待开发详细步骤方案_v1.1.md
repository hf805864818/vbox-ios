## 8. Boot-H · 启动流程域（7 项）

### 🔴 Boot-H4 · 启动 10s 超时兜底 — P1

**问题**：iOS SplashGate 三重退出（最短时长 + 数据就绪 + **10 秒强制兜底**，ContentView.swift:171-190）；Flutter `_bootstrap` 任一 await 卡死则永远白屏转圈（app.dart:268-271 仅有异常错误页无卡死兜底）。

**开发步骤**：
```dart
// app.dart _bootstrap 改造
Future<void> _bootstrap() => _bootstrapWithTimeout().timeout(
  const Duration(seconds: 10),
  onTimeout: () => log('bootstrap 超时兜底，进入错误恢复页'),
);
// 超时页提供「重试」「跳过部分初始化进入」两按钮
```

### 🔴 Net-I3 · 2xx 空数据重试 — P1

**问题**：iOS 豆瓣对「session 未预热返回空数据」和 403/302 做 2 次 + 800ms 间隔定向重试（DoubanService.swift:230-255）；Flutter 仅重试 5xx——**豆瓣首页偶发空白且无自愈**。

**开发步骤**：
```dart
// douban_datasource.dart 请求包装
Future<List<DoubanSubject>> _fetchWithRetry(Future<...> Function() fetch) async {
  for (var i = 0; i < 3; i++) {
    final r = await fetch();
    if (r.isNotEmpty) return r;
    await Future.delayed(const Duration(milliseconds: 800));
  }
  return const [];
}
```

### 🔴 Net-I4 · CMS headers 注入接线 — P1

**问题**：`CmsV10Datasource` 有 headers 参数但 app.dart:219-222 组装时**传空 map**——无 Referer 防盗链。iOS 按 article_html 模式切双 UA + Referer=当前域名 + platform.headers 白名单（RemoteCMSV10Service.swift:43-61）。

**开发步骤**：
```dart
// app.dart 组装处
CmsV10Datasource(
  headers: CmsHeaderComposer.compose(site), // 新建：UA 按 UA 模式切换 + Referer 站点域名 + 白名单注入
)
```

> Net-I1 超时分级（P2 并入）：iOS 每服务资源级超时 10~120s；Flutter 统一 30s，`connectTimeout` 已定义未用。Net-I6 UA 指纹（P3）：iOS 默认 iPhone Safari vs Flutter Android Chrome，仅影响未显式配置 UA 的请求。

## 10. DB-J · 数据层域（1 项 P0）

### 🔴 DB-J1 · 订阅站点残留清理（事务化落库）— P0

**问题**：iOS `saveZhanyuanSites` **事务内先 `DELETE FROM zhanyuan WHERE dyurl = ?` 再批量插入**（同订阅源全量替换，DatabaseManager.swift:267-284）；Flutter 逐条 upsert **无事务、无删除**（subscribe_config_loader.dart:208-234）——**订阅源更新后已下线站点永久残留库中，且中途失败产生半量数据**。

**开发步骤**：
```dart
// subscribe_config_loader.dart 落库改造
Future<void> _persistSites(List<Zhanyuan> sites, String dyurl) async {
  await _db.transaction((txn) async {
    await txn.delete('zhanyuan', where: 'dyurl = ?', whereArgs: [dyurl]); // 先清同源
    for (final s in sites) {
      await txn.insert('zhanyuan', s.toRow(), conflictAlgorithm: ConflictAlgorithm.replace);
    }
  });
}
```
**验收**：订阅源更新后旧站点消失；中断不产生半量数据；全库无 `zhanyuan` 残留。

> 登记不强改（契约偏差管理）：DB-J2 迁移链版本语义错位（iOS v1 八表/v3 建 download；Flutter v1 九表/v3 建索引——最终 v4 收敛一致，**在 schema.dart 头注释登记两端 v1/v3 语义差异**即可，勿动历史迁移）；DB-J3 zhanyuan.searchUA DDL 默认值差异（代码层已兜底，登记）；DB-J4 UserDefaults 迁移死契约（Android 无旧数据，标记键保留兼容）；DB-J5 并发模型（sqflite 串行 vs GRDB Pool，大表性能观察项）。
