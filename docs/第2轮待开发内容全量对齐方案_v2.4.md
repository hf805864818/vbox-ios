## 5. S 族详细开发步骤方案（★本版新增）

### S-04 长按倍速手势接线（P0，先做——已实现差接线）
1. 播放页手势层（`player_controls_view.dart` 或手势宿主）给视频区包 `GestureDetector`（`onLongPressDown`/`onLongPressUp`/`onLongPressCancel`）。
2. 构造 `LongPressSpeedController`：`longPressSpeed` ← `PlaybackSettings` 已读的 `player_long_press_speed`；`currentSpeed` ← `PlayerController.speed`；`setSpeed` ← `PlayerController.setSpeed`。
3. 手势回调接线：`begin()` → UI 提示浮层（对齐 iOS「2.0x 倍速中」角标）；`end()` → 恢复 + 关闭浮层。
4. 单测：begin/end 幂等性已有——补一条「UI 接线冒烟」（长按后 `speed == 2.0`，松开后还原）。
- **验收**：播放页长按 0.3s 进入 2.0x（角标提示），松开恢复原倍速；设置里改 `player_long_press_speed` 生效。

### S-01 切片资源设置分区（P1）
1. `settings_page.dart` 把「待实现」壳中的「切片源」替换为真实分区「切片资源」（对齐 iOS `SettingsViews.swift:399-457` 三入口）。
2. 行 1「启用兜底切片资源」：`VboxSettingsRow.toggle` ↔ `PrefsManager.set('fallback_enabled')`；副文案显示当前状态（对齐 iOS Toggle 绑定 `spiderManager.fallbackEnabled`）。
3. 行 2「管理自定义切片源」：导航页（列表 + 增删改）↔ `custom_fallback_sites`（JSON 数组字符串读写；`prefs_manager.dart` 已注册该键，直接复用类型化接口）。
4. 行 3「管理自定义解析器」：同上模式 ↔ `user_parsers`。
5. 行 4「双模式」：toggle ↔ `enable_dual_mode`（type=3 HTTP API 走原生链路；Spider 域请求分流处加开关判断）。
6. 「站源管理」壳同步替换为真实分区（对齐 iOS `SettingsViews.swift:467`，站点启停/排序，读写站点表）。
7. 备份还原：`custom_fallback_sites`/`user_parsers` 已在备份敏感清单外——按 `backup_service.dart` 现有分组补进「站点/订阅」类。
- **验收**：四键全部有 UI 读写入口；iOS 迁移数据（同一 UserDefaults/SharedPreferences）在 Flutter 端可读可改可备份；Spider 兜底逻辑真实生效（关兜底 → 无源时不走 fallback）。

### S-02 云盘播放 · 百度网盘（P2）
1. 授权中心：设置页「网盘播放」分区 → 授权中心页（对齐 `CloudAuthCenterView`：百度双 Token 展示 + 扫码登录框架预留位）。
2. Token 层：`BaiduAuthStore`（Token 持久化 + 刷新 + `baidu_verify_cooldowns_v1` 冷却窗口，防验证码风暴）。
3. 播放路由：网盘文件 → 直链解析（转存/取回链接）→ 走既有 `PlaybackRoute`（复用 R-04 MDK / 系统后端）。
4. 缓存层：按 iOS 键位一一对应实现播放项/列表/分享上下文/路由诊断缓存（`baidu_*_cache_v1` ×6 + `baidu_route_diagnostics_v1`）。
5. 单测：冷却窗口逻辑、缓存命中/过期；真机验收：网盘视频起播。
- **验收**：百度网盘授权后可浏览目录并起播；二次进入命中缓存秒开；风控验证按冷却节流。

### S-03 云盘播放 · 夸克网盘（P2）
1. 设备指纹：首启生成并持久化 `quark_device_id`（对齐 iOS 夸克 API 的设备参数）。
2. 目录/转存缓存：`quark_vbox_folder_cache_v1`（vbox 专用目录）+ `quark_saved_fid_cache_v1`（已转存文件）。
3. 授权中心复用 S-02 框架（扫码登录预留位对齐 iOS）。
4. 接 `PlaybackRoute` 起播（同 S-02 第 3 步）。
- **验收**：夸克网盘授权浏览起播；转存命中缓存不重复转存。

### S-05 开发调试增强（P3）
1. 日志调试分区加「日志级别」行：Menu/SimpleDialog 四档（verbose/info/warn/error）↔ `app_dev_log_level`（备份清单已含，UI 补齐后端到端通）。
2. 「DNS 缓存清理」入口 ↔ `dns_cache_clear`（执行一次 HttpServer/自定义 DNS 缓存清空后写时间戳）。
3. 「调试浮层」toggle ↔ `show_debug_overlay`（全局悬浮帧率/请求日志开关，可先做骨架：读键 + Provider 开关 + 占位浮层）。
- **验收**：三键全部有 UI 入口且行为可见（级别切换后日志过滤生效）。

### S-06 启动迁移与崩溃恢复（P2，挂 L-05 前后）
1. `main()` 初始化末尾：读 `app_last_launch_version` ≠ 当前版本 → 触发迁移钩子（v2.2 迁移族）+ 写回当前版本。
2. 启动时读 `app_log_crash_marker`：上次正常退出时清、运行中置位 → 本次启动检测到置位则弹「上次异常退出」提示（附查看日志入口），随后清位。
3. 桌面端（Windows/macOS）同逻辑（SharedPreferences 通用）。
- **验收**：杀进程重启出现提示；正常退出重启无提示；版本升级触发一次迁移。
