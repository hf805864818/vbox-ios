## 1. TV-F01 · TV 遥控器（D-pad）焦点导航专项核查（★本版核心）

### 1.1 实码证据（全部本机 grep 实测）

| 检查项 | 结果 | 证据 |
|---|---|---|
| 焦点组件四件套（`focus_ring` / `input_shortcuts` / `ten_foot_scaler` / `hover_affordance`）在 pages/shell/widgets 的引用 | **零引用** | `lib/presentation/widgets/input/` 下 4 文件全部悬空 |
| `home_shell_page.dart` | 仅 1 处全局 `FocusTraversalGroup` + autofocus（L85-87） | 入口级，无页面内导航 |
| `home_page.dart`（首页海报网格） | **0 处** Focus 相关 | D-pad 无法在海报间移动 |
| `detail_page.dart`（详情/线路/剧集选择） | **0 处** | D-pad 无法选线路/剧集 |
| `settings_page.dart`（设置行导航） | **0 处** | D-pad 无法切换设置项 |
| `category_page.dart`（分类网格） | **0 处** | 同上 |
| `search_page.dart` | 仅 1 个 `FocusNode _focus`（L42，输入框自动聚焦） | 非导航用途 |
| 主题层十英尺（TV 大字体/大间距）缩放 | **零命中** | `UiMode.tv` / `ten_foot` 无主题分流 |

### 1.2 对照 VBOX_PLAN 要求（§T.4 焦点系统 / §T.6 十英尺主题 / G-10）

总方案 T.4 明确 TV 焦点五铁律（FocusTraversalGroup 全局 / 可见焦点环 / 边界环绕 / 默认焦点 / 遥控按键映射），T.6/T.7 要求十英尺主题与布局规范。**当前状态：组件已建（widgets/input/ 四件套，G-01 TV 形态 v6.18 交付的骨架）但从未在任何业务页面接线**——与 S-04（长按倍速）同属「实现完忘了接线」，但范围是**全页面级**。

### 1.3 TV-F01 开发步骤（P0）

1. **全局接线**：`home_shell_page.dart` 的 `FocusTraversalGroup` 下按 `UiMode` 注入 `InputShortcuts`（方向键→Focus 移动 / OK→激活 / 返回→pop / 菜单→上下文 / 长按 OK→详情）。
2. **首页**：海报网格每卡片包 `Focus`（`canRequestFocus: true`）+ `FocusRing` 选中环 + 网格 `FocusTraversalGroup`（方向遍历 `WidgetOrderTraversalPolicy` 修正为 `ReadingOrderTraversalPolicy`）；底栏 Tab 纳入遍历组。
3. **详情页**：线路 ChoiceChip / 剧集 ActionChip / 播放按钮接入焦点链；OK 键选中即播（对齐 iOS 点按语义）。
4. **设置页**：`VboxSettingsRow` 封装层加焦点态（选中环 + onKey OK 触发 onTap / 开关切换）。
5. **分类/搜索/直播/网盘等网格与列表页**：同模式批量接线（`VboxPosterCard` / `VboxQuickGrid` 封装层统一加，一处改动全页生效——**优先做封装层而不是逐页**）。
6. **十英尺主题**：`vbox_theme.dart` 按 `UiMode.tv` 分流字号/间距放大（T.6），挂 `TenFootScaler`。
7. **遥控按键映射**：`InputShortcuts` 统一注册（对齐 T.5 表：D-pad 四向 / OK / BACK / MENU / 长按 OK / 数字键选台——直播页）。
8. **验收**：TV 模拟器 D-pad 全流程——底栏切 Tab → 海报网格移动 → 进详情 → 切线路选集 → 播放 → 控制条操作 → 返回；全程焦点环可见、无焦点丢失死角（对照 `真机验收清单_G09_G10.md` 10-1~10-17）。

## 2. S-07 · 平台层播放器悬空组件族（import 级审计，★收编 S-04）

### 2.1 悬空清单（9 文件，零业务 import）

| # | 文件 | 批次 | 职责（iOS 对应） | 悬空后果 |
|---|---|---|---|---|
| 1 | `pip/long_press_speed.dart` | C-05 | 长按倍速（`PlayerViewsV2.setupLongPressGesture`） | v2.4 已列 **S-04** |
| 2 | `subtitle_parser.dart` | C-08 | 字幕 SRT/VTT/ASS 解析（`SubtitleParser.swift`）+ `SubtitleTrack` 二分查找 | **字幕功能整体不可用**（解析器、轨道类全写完零调用） |
| 3 | `playthrough.dart` | C-05 | 自动连播（`AutoPlayNextController`，ended→onAdvance） | 无自动下一集 |
| 4 | `media_url_checker.dart` | — | 直链有效性校验 | 播放前不校验 |
| 5 | `pan_player.dart` | F-08 | 网盘播放编排（NodePanResolver + `cloud_play_item_cache_v1` 缓存） | 网盘播放入口未接 |
| 6 | `remux_proxy.dart` | C-07 | 转封装代理 18081（MKV/FLV/TS→fMP4，`-c copy`） | **R-03 复杂封装回退的实际执行器悬空** |
| 7 | `go_proxy_client.dart` | C-10 | Go 代理客户端 10078（Quarkproxy：流重写/缓存） | **IMG-01/F-01 的代理通路执行器悬空** |
| 8 | `pip/background_play.dart` | — | 后台播放 | iOS 后台音频语义缺失 |
| 9 | `pip/pip_controller.dart` | — | 画中画控制器（`pip.dart` barrel 转发不算） | PiP 未接 |

> **注意**：`pip_strategy`（2 处）/ `pip_lifecycle`（3 处）/ `channel_player`（2 处）/ `player_channel_bridge`（3 处）有真实消费，不在悬空清单。

### 2.2 定性

与 S-04 同一性质：**平台层完成、表现层零接线**。这暴露「批次交付完成 ≠ 功能可用」——C-05/C-07/C-08/C-10/F-08 批次都登记为已交付（有单测），但用户视角功能全部不可用。**建议对全部批次产物做一次 import 级消费审计纳入 CI**（新增守卫脚本，防止再犯）。

### 2.3 S-07 开发步骤（P0，收编并替代 S-04）

1. **播放页（R-02）一并接线族**：播放页落地时同步接 `subtitle_parser`（字幕面板 + 轨道选择 + 外挂字幕文件加载）/ `playthrough`（ended→选集下一集 + 设置开关「自动连播」）/ `long_press_speed`（手势）/ `media_url_checker`（开播前直链探测→走 R-03 回退判定）。
2. **R-03 落地时接 `remux_proxy`**：复杂封装判定（`RemuxPlan`）→ 启动 18081 转封装 → 直连后端播 fMP4。
3. **IMG-01/F-01 落地时接 `go_proxy_client`**：启动 10078 Go 代理 → 封面/网盘流走 `registerStream` 重写。
4. **网盘播放（S-02/S-03）接 `pan_player`**：分享链接→条目→地址→`cloud_play_item_cache_v1` 缓存→`PlayerController` pan 路由。
5. **PiP/后台**：Android 真 PiP 接 `pip_controller`；`background_play` 接前台服务（G-02-C 的 MediaPlaybackService）。
6. **守卫**：新增 `scripts/check_platform_wiring.py`——扫描 `lib/platform/` 全部公开类在 `lib/presentation/` / `lib/data/` 的 import 命中，零命中即失败（barrel 排除）。
- **验收**：① 字幕可加载显示（SRT/VTT/ASS 三格式）；② 播完自动下一集；③ 长按倍速；④ MKV 走转封装播放；⑤ 守卫脚本入 CI 且当前零悬空（或登记豁免）。
