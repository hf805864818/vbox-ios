### 🔴 D-01 · 网盘云源识别（`isCloudVideo` + `☁️` 前缀）— P1

**问题**：iOS 详情页有网盘云源识别逻辑，Flutter 无。

**iOS 实现**：
- [PlayerViews.swift:104](file:///workspace/vbox/Views/PlayerViews.swift#L104)：`isCloudVideo = video.vodRemarks?.hasPrefix("☁️") == true`
- 云源标记后：
  - 剧集列表改为网盘链接列表（`cloudDriveGroups`）
  - 播放源 chips 改为网盘类型分组（百度/夸克/UC/阿里/115/迅雷/123/139/189）
  - 每个网盘独立展开状态（`driveExpandStates`）
  - 夸克拆三条线路（原画直链 / 备用夸克普画转码 / 夸克Node）

**Flutter 现状**：
- `detail_page.dart` **全文件 0 引用** `isCloudVideo`/`☁️`/`cloudDriveGroups`/`driveExpandStates`
- 网盘链接与普通播放源混在一起，无分组展示

**开发步骤**：
1. `PlaybackDetail` 新增 `isCloudVideo` 判定（`vodRemarks` 以 `☁️` 开头）；
2. 云源详情页 UI 分支：
   - 剧集列表区域替换为网盘链接分组列表；
   - 每个网盘分组显示：网盘图标 + 网盘名称 + 文件数 + 展开/收起按钮；
   - 点击网盘分组 → 展开显示该网盘下的文件列表；
3. 网盘分组排序（接入 `CloudDriveSortManager` 已有排序逻辑）；
4. 夸克/UC/百度拆分多条线路（原画/备用/Node）。

**验收**：云源详情页显示网盘分组；夸克显示 3 条线路；分组可展开收起。

### 🔴 D-04 · 点击剧集直接播放（`handleEpisodeSelect`）— P1

**问题**：iOS 详情页点击剧集直接播放，Flutter 需要再点「立即播放」按钮。

**iOS 实现**：
- [PlayerViews.swift:223](file:///workspace/vbox/Views/PlayerViews.swift#L223)：`handleEpisodeSelect(episode)` 直接触发播放
- 点击剧集 → 选中并立即播放（无二次确认）

**Flutter 现状**：
- `detail_page.dart:599`：剧集宫格 `onSelect` 只更新 `_episodeIndex`，**不触发播放**
- 用户需再点「立即播放」按钮才能播放

**开发步骤**：
1. `_EpisodeGrid` 的 `onSelect` 回调改为：
   - 更新 `_episodeIndex`；
   - 立即调用 `_play()`（无需再点按钮）；
2. 播放按钮保留（用于当前选中剧集重播）；
3. 网盘剧集点击同样直接播放（D-01 实现后接入）。

**验收**：点击剧集直接播放；播放按钮用于重播。

### 🔴 D-05 · 网盘链接 vboxParams 定位（`vbox_fid`/`vbox_fsid`/`vbox_node`）— P2

**问题**：iOS 详情页网盘链接支持 `vbox_fid`/`vbox_fsid`/`vbox_node` 参数定位指定剧集，Flutter 无。

**iOS 实现**：
- [PlayerViews.swift:3049-3051](file:///workspace/vbox/Views/PlayerViews.swift#L3049)：阿里云盘 `vbox_fid` 定位文件
- [PlayerViews.swift:3138-3140](file:///workspace/vbox/Views/PlayerViews.swift#L3138)：百度网盘 `vbox_fsid` 定位文件
- [PlayerViews.swift:3710-3728](file:///workspace/vbox/Views/PlayerViews.swift#L3710)：Node 托管盘 `vbox_node` 定位文件（playID 稳定匹配）
- [PlayerViews.swift:3183-3185](file:///workspace/vbox/Views/PlayerViews.swift#L3183)：夸克网盘 `vbox_fid` 定位文件

**Flutter 现状**：
- `detail_page.dart` **全文件 0 引用** `vbox_fid`/`vbox_fsid`/`vbox_node`
- 网盘链接点击后从第 1 集开始播放，无法定位指定剧集

**开发步骤**：
1. `PlaybackEpisode` 新增 `vboxParams` 字段（Map<String, String>）；
2. 详情页网盘链接点击时：
   - 从链接 URL 提取 fragment 参数（`vbox_fid`/`vbox_fsid`/`vbox_node`/`vbox_route`）；
   - 传递给 `PanPlayer` / 播放器；
3. `PanPlayer` 接入 `vboxParams`：
   - `vbox_fid` → 文件列表中定位对应文件；
   - `vbox_fsid` → 百度网盘文件列表中定位对应文件；
   - `vbox_node` → Node 托管盘 playID 稳定匹配（F-P26 实现后接入）；
   - `vbox_route` → 夸克线路偏好；
4. 播放器选集面板接入：
   - 显示文件列表时，高亮 `vbox_fid`/`vbox_fsid`/`vbox_node` 对应的文件。

**验收**：详情页网盘链接点击第 N 集 → 播放器直接定位到第 N 集；支持 `vbox_fid`/`vbox_fsid`/`vbox_node`/`vbox_route` 参数。
