## 1. 新发现 UI 遗漏明细（60 → 64 项）

### UI-B1 · 触感反馈全端缺失（P2，半天级）

iOS 10 处语义清单（对齐时逐一映射 `flutter/services` 的 `HapticFeedback`）：

| iOS 位置 | 触发点 | Flutter 对应 |
|---|---|---|
| `ContentView.swift:98` | **Tab 切换**（light） | `VboxBottomNav`（全端壳层，一处加全端生效） |
| `PlayerViewsV2.swift:1741,8425` | 播放器手势确认（medium） | R-02 播放页（待开发项验收点） |
| `PlayerViewsV2.swift:10538,10915` | 选集/清晰度切换（selection） | R-02 播放页 |
| `DoubanHomeView.swift:496` | 豆瓣栏目切换（selection） | 首页 section 切换（C-02） |
| `WelfareHomeView.swift:184,518,519` | 福利平台网格（light+medium） | `welfare_home_page`（已交付页，实锤可补） |
| `ProfileView.swift:585` | 个人中心功能宫格（medium） | `profile_page`（已交付页，实锤可补） |

**实施**：封装 `VboxHaptics.tap()/select()/medium()` 工具类（单点收口，TV/桌面自动 no-op）；已交付页（Tab 壳/福利/个人中心/豆瓣切换）本批接线；播放器 2 类触感挂 R-02 验收点。

### UI-B2 · 下拉刷新覆盖不足（P1 首页实锤 + 验收点补挂）

| iOS 页面 | Flutter 现状 | 处置 |

| 短剧 `ShortDramaView:199` | ❌ 无 | 页面已交付 → 补 |
| MDTV×4（`MDTVViews` 238/364/448/550） | ❌ 无 | E 族待开发 → **验收点** |
| 音乐×2（`MusicView` 440/476） | ❌ 无 | G 族待开发 → 验收点 |
| 福利平台 `FuliPlatformMainView` | ✅ 已有（welfare_spider_main_page） | 已对齐 |
| 三歌分类+列表（SangeCategory/SangeList） | ❌ 无 | G 族音乐子页 → 验收点 |
| 源发现 `SourceDiscoveryView` | ❌ 无 | `source_discovery_view` 已有 → 补 |

**实施**：统一 `VboxRefreshWrapper`（`CupertinoSliverRefreshControl` 形态，配 `VboxScrollBehavior` 回弹）；首页/短剧/源发现三个已交付页本批接线；E 族/G 族清单条目追加「下拉刷新」验收点。

### UI-B3 · 骨架屏缺失（P2）

- iOS 首页加载 = `DoubanSkeletonCardItem` 卡片骨架（[MainViews.swift:2319](file:///workspace/vbox/Views/MainViews.swift)）；排行榜 = `ChartSkeletonRow`（[DoubanRankingView.swift:358](file:///workspace/vbox/Views/DoubanRankingView.swift)）。
- Flutter 首页/排行榜当前是居中菊花——**形态与 iOS 不一致**（非功能缺失，是加载态质感）。
- **实施**：① 通用 `VboxSkeletonCard`（圆角灰块 + shimmer 微光，零第三方依赖手写）；② 首页 banner/横滚区、排行榜列表接入；③ 其余页保持菊花（iOS 也非全骨架，仅这两处）。

### UI-B4 · 启动页动画缺失（P3）

- iOS：四张字母图按 **左上 V(0) → 左下 b(0.08) → 右上 o(0.14) → 右下 x(0.20)** 错峰飞入拼合成 Logo，再 swoosh 划线定版（图片资产 Flutter 侧已具备：`assets/splash/vbox_letter.png` 单图为合成版）。
- Flutter：`BrandLogo` 静态展示，**无编排动画**。
- **实施**：`SplashScreen` 用 4 个 `TweenAnimationBuilder`（offset + opacity，staggered interval 0.08s）+ swoosh 用 `CustomPainter` 划线动画（或静态渐变条）；资源可裁剪单字母 PNG（iOS imageset 已有，搬运即可）。

### UI-B5 · 微动效密度（观察项 · 不单列待开发）

iOS `withAnimation` 151 处 vs Flutter `Animated*` 6 处。**视觉语言（色/字/圆角/质感）已对齐，此处是动效质感差异**。处置：不设独立条目；各待开发批次（R 播放器/L 列表/S 设置）实现时按 iOS 参考图的过渡自然补 `AnimatedSwitcher/AnimatedOpacity`（如 Tab 底栏 `.move+.opacity` 组合、Banner 指示器过渡）；J.3 终检时统一审计。
