```dart
if (route is WelfareUnsupportedRoute) {
  Navigator.of(context).push(MaterialPageRoute(
    builder: (_) => UnsupportedPlatformPage(...),

```

## 3. 关键路径（v2.9 修订）

```
⓪ ⓪′ ① 沿 v2.8 不变（PF-01-MAC/S-07守卫/TV-F01/UI-A3/UI-A2）
★ 新插队：UI-C1 福利平台专页（P0——主 Tab「福利」当前 5 原生平台全 Unsupported，
   是用户可见的最大功能黑洞；数据/路由已就绪，纯表现层可与 R 族并行）
② UI-A1+B2+B3 首页三合一
③ S/ND/L 族 …（沿 v2.8）
```

> 排期理由：福利是 5 Tab 主入口之一，UI-C1 修复前点击任一原生福利平台（香蕉秀/每日对决/看料/MissAV/艾旦）都是「UnsupportedPlatformPage」——这是**比首页结构更优先的用户可见缺陷**，建议提至与 R 族并行或紧随⓪′之后。
