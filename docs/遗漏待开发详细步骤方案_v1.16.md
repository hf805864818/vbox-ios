**落地口径**：新增全屏 [PlayerPage](file:///workspace/lib/presentation/pages/player/player_page.dart)，对齐 iOS `PlayerViewsV2` 承载结构：

- 详情页「立即播放」进入播放页；网盘分享播放接入同一全屏页（`0e80dfa`）；退出仅 `pause` 不销毁实例。

**验收**：点「立即播放」进入全屏播放页，控制条/弹幕/选集/画质/倍速/内核面板可用；返回详情页状态保持。

## 2. Wave B 交付记录（分发闭环）

### ✅ K-更1 · 自更新器 — 已交付

[updater.dart](file:///workspace/lib/platform/update/updater.dart)（`ChangeNotifier`，依赖全可注入便于单测）：

1. **`check`**：拉取 GitHub Releases `?per_page=1` → 归一 [UpdateManifest] → 与 `AppInfo.version` 数值化比较；5 分钟内非强制检查走内存缓存短路；
2. **`download`**：按 `RemoteSourceStrategy` 三级降级链（主代理 → 备用代理 → 直连）流式下载当前平台资产 → 可选 SHA-256 校验；进度经通知器广播；支持取消（token 失效）；
3. **`install`**：Android 走 [UpdateInstallBridge](file:///workspace/lib/platform/update/update_install_bridge.dart)（应用内安装器 + 未知来源授权引导）；桌面端交系统默认程序打开，失败回退发布页。

### ✅ K-更2 · 版本分发清单 — 已交付

[update_manifest.dart](file:///workspace/lib/domain/entities/update/update_manifest.dart)：定义 `version.json` 契约（版本 / 构建号 / 说明 / 发布页 / 资产[平台·URL·sha256]），并支持把 GitHub Releases API JSON **归一到同一模型**（对齐 iOS 现有拉取口径）。

### ✅ K-更3 · Android 安装权限与 FileProvider — 已交付

- [AndroidManifest.xml](file:///workspace/android/app/src/main/AndroidManifest.xml)：新增 `REQUEST_INSTALL_PACKAGES`（API ≤ 28 另补 `WRITE_EXTERNAL_STORAGE`）；
- [file_paths.xml](file:///workspace/android/app/src/main/res/xml/file_paths.xml)：新增 `updates/` 白名单（`files-path` + `external-files-path`）；
- [UpdatePlugin.kt](file:///workspace/android/app/src/main/kotlin/com/vbox/player/UpdatePlugin.kt)：`canInstall` / `openInstallPermissionSettings` / `installApk` 三方法，[MainActivity.kt](file:///workspace/android/app/src/main/kotlin/com/vbox/player/MainActivity.kt) 注册。

### ✅ M-安1 · macOS Release entitlements — 已交付

[Release.entitlements](file:///workspace/macos/Runner/Release.entitlements) 补齐 `com.apple.security.network.client` / `network.server` / `cs.allow-jit`；[DebugProfile.entitlements](file:///workspace/macos/Runner/DebugProfile.entitlements) 补 `network.client` 对齐。
