## 0. 本轮深扫 · 核心发现

### 🔴 发现 A：**加载提示文案体系缺失**（17 处 `loadingMessage` vs Flutter 0 处）

iOS `PlayerViewsV2` 有完整的多场景加载文案：
| 场景 | iOS 文案 |
|---|---|
| 解析中 | `正在解析播放地址...` |
| 切换内核 | `正在切换 MPV-MoltenVK...` |
| 切换集数 | `正在跳转到 12:34...` |
| 获取网盘地址 | `正在获取百度视频地址...` |
| 缓冲首帧 | `正在缓冲首帧...` |
| 兼容内核 | `正在使用兼容内核...` |
| 播放失败 | `播放失败` |

Flutter 播放器**全仓 0 引用**——用户不知道当前在解析/切换/缓冲。

### 🔴 发现 B：**倍速档位不一致**

| 端 | 倍速档位 |
|---|---|
| iOS | `0.5, 0.75, 1.0, 1.25, 1.5, 2.0, 3.0`（7 档） |
| Flutter | `0.5, 0.75, 1.0, 1.25, 1.5, 2.0`（**缺 3.0 档**） |

### 🔴 发现 C：**长按倍速提示浮层缺失**

iOS `:905` `showLongPressSpeedHint`（长按倍速激活时显示浮层提示）+ `:1739/1749/6769/6830/6972` 状态管理；Flutter 有 `LongPressSpeedController`（S-07）但**无提示浮层**。

### 🔴 发现 D：**网盘兜底链逻辑缺失**

iOS 有完整网盘兜底链：
- `switchToQuarkFallback`（`:4228/4234`）：原画 403/连接中断/首帧超时 → 切 m3u8 兜底
- `switchBaiduFile`（`:1466-1491`）：百度多文件选集切换
- `quarkFallbackURL/Headers/Source/Attempted/TimeoutTask`（`:1027-1031`）：完整兜底状态机

Flutter 网盘播放**无兜底链**——原画失败即失败。

### 🔴 发现 E：**前后台恢复保护缺失**

iOS `handleSceneBackground`（`:2753-2770`）：
- 后台播放开关关闭时暂停播放器
- 进度保存移到后台队列（防 watchdog 杀进程）
- 显式恢复 `isIdleTimerDisabled`（系统可能重置）

Flutter **无 `AppLifecycleState` 监听**——切后台可能继续播放或被杀。

### 🔴 发现 F：**音乐播放器页面缺失**

Flutter `music_player.dart`（`MusicPlayerController`）存在，但**无对应页面**——音乐功能无 UI 入口。

## 1. 本轮新增（89 → 95 项）

### 🔴 UI-F18 · 播放器加载提示文案体系 — P1

**问题**：见发现 A。Flutter 播放器无加载文案，用户不知道当前在解析/切换/缓冲。

**开发步骤**：
1. 新建 `PlayerLoadingState`（对齐 iOS `@Published loadingMessage`）；
2. 按场景切换文案：解析中 / 切换内核 / 切换集数 / 获取网盘地址 / 缓冲首帧 / 兼容内核 / 播放失败；
3. 接入 `PlayerControlsView` 中央覆盖层（加载时显示文案 + 转圈）；
4. 对齐 iOS 磨砂皮肤适配。

**验收**：各场景文案正确显示；与 iOS 文案一致；加载完成自动隐藏。

### 🔴 UI-F21 · 网盘兜底链（Quark/Baidu）— P1

---

### 🔴 UI-F22 · 前后台恢复保护 — P1

**问题**：见发现 E。Flutter 无 `AppLifecycleState` 监听。

**开发步骤**：
1. 播放器接入 `WidgetsBindingObserver`（对齐 UI-E4 生命周期）；
2. 切后台：按 `backgroundPlay` 开关决定是否暂停（对齐 iOS `:2762-2768`）；
3. 进度保存移到后台队列（防 watchdog）；
4. 回前台：恢复播放 + 恢复 `isIdleTimerDisabled`；
5. 与 S-07 后台播放接线联动。

**验收**：切后台按设置暂停/继续；回前台恢复；进度不丢；无 watchdog 杀进程。
