## 3. 目标架构：统一 UI + 横竖双形态自适应

### 3.1 设计目标与不变式

- **一套令牌**（颜色/字号/圆角/间距/阴影）→ 全端共用（批次 A）。
- **一套组件库**（卡片/胶囊/分区头/剧集 chip/浮层/Toast/TabBar）→ 全端共用。
- **一套页面代码** → 通过布局适配层在竖屏/横屏产出不同排布。
- **输入差异隔离**：触摸 / 遥控 D-pad / 鼠标键盘 → 仅影响焦点与交互反馈，**不改版式**。
- **不变式**：不改 `vbox/`（D1 零改造）；不新增与契约冲突的字段（D17 门禁）。

### 3.2 形态解析（检测 + 功能开关）

**输出**：`UiForm { portrait, landscape }`（本轮收敛为 2 种）+ `InputModality { touch, remote, mouseKeyboard }`。

**判定输入（优先级从高到低）**：

1. **用户功能开关（最高优先）**：设置项「显示模式：自动 / 手机（竖屏）/ 大屏（横屏）」→ **新增 prefs 键** `app_ui_form_override`（string：`auto|portrait|landscape`，默认 `auto`），走 **D17 契约变更门禁**。
2. **平台特征**：`Platform.isAndroid/isIOS/isMacOS/isWindows`；Android 侧探测 `PackageManager.FEATURE_LEANBACK`（TV）。
3. **窗口最短边**：`MediaQuery.shortestSide`（手机 < 600dp；大屏 ≥ 600dp）。
4. **方向**：`MediaQuery.orientation`。
5. **输入模态**：`hasTouch` / `hasDpad`（Android `FEATURE_LEANBACK` 且无触摸）/ `hasPointer`。

```
resolveForm(env) -> UiForm:
  if override == 'portrait'  -> portrait
  if override == 'landscape' -> landscape
  if isTV || isDesktop       -> landscape          // TV/PC/mac 恒横屏
  if shortestSide >= 600dp   -> landscape          // 平板/折叠展开按横屏
  else                       -> 依 orientation     // 手机随方向
```

### 3.3 布局适配模型

| 维度 | 竖屏（手机） | 横屏（TV / PC / mac / 手机横屏） |
|------|-------------|-------------------------------|
| 导航 | **底部悬浮胶囊 TabBar** | **左侧 NavigationRail**（同图标体系 + 同标签） |
| 内容列数 | 2–3 列 | 5–8 列 |
| 详情页 | 全屏页 | 列表 + 右侧详情面板 |
| 浮层 | 底部/居中弹窗 | 右侧抽屉 / 居中弹窗（同组件改锚点） |
| 最大内容宽 | 全宽 | 居中约束 1440–1680dp + 安全边距 |
| 字体/间距 | 基准档位 | 同档位；**TV 叠加 1.2–1.5× 十英尺缩放** |

载体：`AdaptiveScaffold` + `ResponsiveGrid` + `ContentPanel` + `AdaptiveDialog`。

### 3.4 输入适配层

| 模态 | 行为 |
|------|------|
| 触摸 | 点击/长按/滑动 |
| 遥控 D-pad | 焦点遍历、可见焦点环、OK/返回/菜单映射（沿用 T.4/T.5） |
| 鼠标键盘 | hover 态、右键、快捷键（空格播放 / 方向键 seek / Esc 返回） |

> **原则**：**只加反馈层，不改版式** → 满足「四端同 UI」。

### 3.5 播放器横竖屏双态（对齐 UI 图 19）

**共性控制集（两态一致）**：返回 · 进度条(当前/总时长) · 播放/暂停 · 下一集 · 弹幕开关 · 弹幕输入(「请文明发送弹幕」) · 倍速(1x，菜单 0.5–2x) · 画质(蓝光，菜单 标清/高清/蓝光) · 选集 · 解码/后端(自动/系统/MDK/VLC/MPV/IJK/阿里)。

| 态 | 差异 |
|----|------|
| **竖屏** | 视频满屏；底部控制条单行；弹幕设置 = 居中卡片(开启/透明度 80%/字号 16px/显示区域 25–100%) |
| **横屏** | 顶部弹幕层 + 右上图标(cast/音量/弹幕/全屏/更多)；**左侧锁屏**；右侧弹出菜单(倍速/后端/更多：长按倍速·搜索弹幕·加载字幕·片头片尾·自动播放·后台播放·画中画·调试浮层) |

### 3.6 保真度 ≥95% 的可度量定义

| 层 | 指标 | 达标口径 |
|----|------|---------|
| 令牌一致 | 颜色/字号/圆角/间距 | **100%** 取自令牌（R-2/R-3/R-4 守卫） |
| 组件规格 | 卡片/胶囊/Toast/剧集项 | **100%** 对齐 UI基准 §2.5 |
| 页面结构 | 信息架构与层级 | 逐页对齐 UI 图（§2.1），**结构项全中** |
| **视觉相似度** | Flutter 截图 vs iOS UI 图 | **SSIM ≥ 0.95**（或像素差 ≤5%）**逐页达标** |
| 不计入 | 字体族、TV 缩放、焦点环/hover/系统状态栏 | 沿用 UI 基准口径 |

> 「≥95%」以**每页 SSIM**为主指标，辅以「结构项全中 + 令牌/组件 100%」。任一口径不达即判不达标。

### 3.7 视觉回归与守卫

1. **基准入库**：35 张 iOS UI 图归档到 `docs/ui_baseline/ios_ref/`（只读基准）。
2. **Golden 测试**：`flutter test --update-goldens` 产出 Flutter 截图，与基准做 SSIM 比对，**低于阈值即失败**。
3. **守卫脚本**：新增 UI 令牌守卫（R-2 圆角 / R-3 字号 / R-4 主色不散落）。
4. **CI 集成**：视觉回归纳入 `flutter-check.yml`。
